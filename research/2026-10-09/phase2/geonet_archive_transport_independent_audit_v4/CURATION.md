# Curated publication and review boundary

PUBLIC_ALLOWLIST.txt names only authored auditor source, invented tests, generic protocol/context, provenance and safe test/runtime/review metadata. No actual/private input, roster, key, ID, body, receipt, credential, raw external source or collector implementation is included. Isolated review_snapshot, its Git internals, helper raw outputs and temporary files are excluded. Source review grants no actual replay authority.

MANIFEST.json pins every public allowlisted member except itself and SHA256SUMS.txt. SHA256SUMS.txt pins every allowlisted member except itself, including the final manifest. Self exclusions avoid hash cycles. Source snapshot pins retain the exact pre-review source/test/protocol/context bytes. Review metadata and handoff are finalized after first clean without editing those reviewed bytes.

Parent-verifiable closure: parse the line allowlist as unique safe relative POSIX paths; reject absolute or traversal paths, symlink members and duplicate paths. Require each declared member under this packet to be a regular file. Require manifest pin names to equal allowlist names minus MANIFEST.json and SHA256SUMS.txt, and independently recompute every byte count/SHA-256. Require SHA256SUMS.txt names to equal allowlist minus itself and independently recompute each digest. Require every source snapshot member and each contract pin member to be in both the manifest and public copy set, and independently match its bytes/hash. This packet has no runtime dependency bundles; the collector implementation is intentionally absent. Upstream citation links are provenance references, not files to include or execute. Publication must copy exactly the allowlist members, preserving bytes.

This checks curated source publication closure. It does not discover or certify private collection filesystem inventory. The parent separately owns full actual inventory custody, exact plan/summary pins, event/pair/clock/prerequisite verification, pushed source freeze and fresh authorization before bounded replay. Every prior failed/partial artifact remains preserved.
