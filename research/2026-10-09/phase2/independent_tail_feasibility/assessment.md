# Independent large-event development data: release and causal-feasibility audit

10 October 2026. Primary web sources and existing local reports/schema documentation only. No event CSV contents, raw metadata tables, waveform samples, checkpoints or held outcomes were read. No download job, account request or cloud action was started. The parent reports the Chile floor gate was negative; no Huber or covariance continuation is justified by that diagnostic.

**Recommendation: perform a small metadata-only GeoNet moment-tensor/arrival census next.** Its official CMT table provides a route to independently measured Mw labels, and raw local-network miniSEED plus instrument metadata are publicly documented. Whether enough usable independent large events survive the joins is unknown and is the question to answer before acquisition. Alaska is already task-owned and remains the fallback for a limited tail stress test. Japan is scientifically attractive but currently account-gated; no primary raw-waveform mirror suitable for this task was verified.

## 2. Public Japanese “mirrors” that do not solve the problem

[Zazzaro2026, Earthquake Data from Japanese and Italian Seismic Networks, Zenodo22896044](https://zenodo.org/records/22896044), is accessible and small:3.3MB CSV plus README. However, it explicitly contains metadata and six four-second descriptors for15,426 recordings, including2,736 Japanese records. It does **not** include raw waveforms/extraction code. The record also discloses absent unique earthquake IDs, unspecified per-record magnitude scale and incomplete amplitude-unit documentation. Its rendered license field was blank in this tool, so no license is asserted. It cannot reconstruct1/3/5-second observations or establish reliable event separation merely from record rows.

The [GFZ Loviknes et al.2025 KiK-net/K-NET release description](https://datapub.gfz.de/download/10.5880.GFZ.LKUT.2025.001-CVaecnui/2025-001_Loviknes-et-al_Data-Description.pdf) describes eight flatfiles of metadata and processed intensity/spectral measures. Its source waveforms are obtained from NIED. Processing uses whole-record detrending, duration/noise-window selection and acausal filtering. These are useful metadata resources, not an anonymous raw TEAM waveform mirror. Full-event spectra cannot be made causal by labeling them a first-second feature.

These are inspected examples, not a claim that no lawful mirror exists anywhere.

## 3. GeoNet has a concrete label/identity entry point

The official catalogue page links the [GeoNet moment-tensor directory](https://github.com/GeoNet/data/tree/main/moment-tensor). Its public file is [GeoNet_CMT_solutions.csv](https://github.com/GeoNet/data/blob/main/moment-tensor/GeoNet_CMT_solutions.csv); only the directory/README, not CSV rows, was inspected. The README specifies EVENT_ID, Mw, ML, method, station count and variance reduction. Solutions start August2003; they are **not integrated into catalogue QuakeML**. Some IDs are the unresolved placeholder9999999. Dusky Sound and Kaikōura use external USGS W-phase solutions; preserve that provenance. Two inversion-method eras are documented. These facts make an explicit CMT join preferable to silently calling all preferred GeoNet magnitudes Mw. [Official schema/readme](https://github.com/GeoNet/data/tree/main/moment-tensor).

The [GeoNet catalogue documentation](https://www.geonet.org.nz/data/types/eq_catalogue) says individual-event QuakeML contains detailed arrivals and alternative information; QuakeSearch summaries do not contain arrivals or additional magnitudes. The [data policy](https://www.geonet.org.nz/policy) supplies separate citation DOIs for catalogue, CMT, waveforms and station metadata. These endpoints therefore offer an actionable, small label/arrival feasibility audit without downloading seismic samples.

The [NZGMDB author code/wiki](https://github.com/ucgmsim/nzgmdb/wiki), currently described as v4.3, documents source, site and phase tables plus both raw miniSEED and processed records in its pipeline outputs. It also uses retrospective PhaseNet arrivals and whole-record quality filtering. A documented output folder is not proof that every output is publicly downloadable. The [2024 author paper](https://lee-robin.github.io/files/Journal/Hutchinson_2024_GMDB_BSSA.pdf) gives the OSF project `https://osf.io/q9yrg/?view_only=05337ba1ebc744fc96b9924de633ca0e`; both project/API retrieval failed in this web tool, so exact version bytes/license/file availability remain unresolved. Its v3.4 cohort and later reported v4.3 cohorts must not be interchanged. The paper also distinguishes measured CMT Mw from corrected/converted local or body-wave magnitudes. No homogeneous-Mw or tail-count claim follows from the database's total record count.

The raw archive can avoid reliance on that processed release. GeoNet reports continuous200Hz HN strong-motion streams since February2020 and older triggered/continuous mixtures. Vol1 converts to mm/s² with static sensitivity; Vol2 applies frequency-domain response/filter/integration processing. Start from raw miniSEED for the causal track. [Official strong-motion documentation](https://www.geonet.org.nz/data/types/strong_motion). Availability, saturation, response epochs and orientation still need actual verification; an archive documentation page does not certify them.

## 4. One recommended bounded next action — metadata census, not waveform acquisition

**Proposed next authorization/implementation scope:** a local, immutable GeoNet CMT-to-catalogue census, maximum30minutes, two CPU threads,100MiB combined transfers, no GPU/AWS resources. Public APIs/repositories only; stop on size/time limits and report incomplete. This is a proposal, not an already executed or frozen protocol.

1. Pin the public GeoNet/data repository revision and retrieve just the CMT CSV and README. Preserve exact bytes/hash, license citation, acquisition date and original row numbers. File size is not currently verified; expect a small table, but enforce the limit before a larger transfer. Use the declared 2003-08-01 through2024-12-31 interval to avoid an open-ended changing cohort.
2. Count unique resolvable event IDs at measured Mw≥5.5,≥6,≥7, by year, method and external-solution provenance. Retain all duplicate/placeholder IDs in a rejection ledger. Do not resolve9999999 by an arbitrary nearest timestamp, convert ML into an “independent” Mw, or treat two solution rows as two earthquakes. This establishes candidate support only.
3. For resolvable Mw≥5.5 IDs, retrieve each event's documented QuakeML from `https://service.geonet.org.nz/fdsnws/event/1/query?eventid=<ID>`. Cap500requests and at most one request per second; report any omitted remainder. Inventory actual recorded P-type picks with station identity and UTC time, alternative magnitudes, and catalog revisions. Do not substitute theoretical arrivals from true hypocentre when picks are absent. Count events with one/three/five distinct station P picks. Pick presence is still not proof of3C raw-prefix coverage or an online trigger.
4. Produce candidate event counts and identity/pick coverage, not predictions or a model-selected cohort. Report possible concentration in one earthquake sequence, and exact counts by native magnitude definition. A later waveform feasibility stage must measure region/locality, record availability and channel response; neither source distance nor origin will become model inputs. No Chile TEST identity/waveform access is required.

**Decision after this census:** if fewer than60 resolvable Mw≥5.5 events or fewer than20 Mw≥6 events have recorded P picks, do not present this as a substantial new high-tail development population; retain it as a possible stress-test resource. These are practical investment thresholds, not power calculations. Passing only earns a small reviewed raw-waveform/response audit. A training plan would then need enough usable events to allocate separate development and final validation with sequence-aware grouping. Do not spend the validation tail to choose a method.

This stage has zero new AWS spend and no bulk-waveform storage. Public access is free; response size and retrieval success remain unmeasured. For later capacity planning only:2,000events×25stations×45seconds×100Hz×3components×4bytes is2.7GB of float32;200Hz doubles that. These are scenarios, not observed cohort/download sizes. Longer archive windows, response metadata and raw/processed copies add overhead. Estimate from a bounded sample before any bulk request.

## 5. Requirements before calling either GeoNet or Alaska a causal benchmark

- Freeze the event population and label channel before scores. Report measured Mw separately from ML/MJMA/MA and equivalent-magnitude conversions. A new regional track does not reproduce TEAM/EPIC headline errors.
- Choose the clock explicitly. A retrospective annotated first-P clock can match the characterization question while remaining an oracle-aligned benchmark. A deployed clock requires a frozen causal picker/association rule and detection latency/misses. A whole-window PhaseNet pick cannot silently become an online trigger.
- Query generous retrieval windows if needed using catalogue time, but expose only the frozen observed prefix. Never use catalogue distance, source location, future nearest-station ranking or theoretical arrivals to construct inference features/availability. Preserve missing stations and unavailable components explicitly.
- Use current-response epochs, physical units, causal conversion/filter state and audited timestamp/resampling conventions. HH velocity and HN acceleration are not interchangeable. Never crop a noncausally processed full trace and claim strict early information.
- Hold entire event/sequence groups apart before any encoder fitting, calibration or method selection. Audit all imported pretrained models for event exposure. A fresh regional dataset is potentially independent; that property must be checked against the exact artifacts used.
- Require a natural bulk cohort as well as tails for a bulk-preservation claim. Alaska's magnitude threshold and the proposed GeoNet CMT census select stronger events; their results alone cannot establish unchanged mean/median error for the small-event deployment population. Preserve the original bulk track and define any new-region bulk evaluation separately.

Japan remains the strongest exact published alternative if an authorized account becomes available. For work possible without that dependency, the GeoNet CMT/arrival census is the smallest concrete step that can establish whether we have a materially larger independent tail population rather than another attractive dataset name.
