[P2] Preserve text-node boundaries for native whitespace semantics
semantic_audit.py:382
Default ElementTree parsing discards comments and coalesces surrounding text before the native literal rules run. For an otherwise eligible native arrival containing `<weight>0</weight><timeUsed> <!--invented-->true</timeUsed>`, the documented XSLT whitespace removal discards the whitespace-only text node before the comment, leaving literal `true` and projecting zero timeWeight. This parser instead produces `" true"`, so the auditor omits timeWeight and incorrectly accepts the pick. References separated from whitespace by comments can likewise acquire incorrect scope. Preserve text-node boundaries when applying the source whitespace policy, or return unknown for scalar content whose interpretation cannot be preserved.
