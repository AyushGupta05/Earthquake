## Fixed inputs and response representation

Only raw **released** counts in [P,P+100t), t∈{1,3,5}, enter the model. Each component is prefix-demeaned independently. The pre-P history is used only by the common validity check in this architecture pilot. It is not a model input, a learned baseline, or a new noise branch. Native amplitudes use the known per-component sensitivity; units remain explicit. Released full-record detrending/resampling and manual P remain benchmark limitations; this is prefix-safe computation on the release, not a raw-stream causality certificate.

One normalized waveform enters the CNN: q/RMS(q), with the existing count-space RMS floor1e−8. Retain six natural-log RMS/peak amplitudes and log duration. B/C native amplitudes are the same count log amplitudes minus **natural log** sensitivity. This avoids a duplicate waveform tensor: (q/g)/RMS(q/g)=q/RMS(q) for positive g away from floors. No integration, differentiation, spectral correction, two-sided filter or response deconvolution is introduced.

Retain the existing34 static fields in all arms. Add72 response fields: ENZ×6frequencies×[log|H/g|,cos phase,sin phase,valid]. Fixed frequencies are0.5,1,2,4,8,16Hz. H is the nominal full native acquisition chain evaluated by ObsPy1.5.1/evalresp with output `DEF`, including every stage and gain exactly once; it is not claimed to equal the effective response after INSTANCE preprocessing. Use the audited source/epoch mapping and inventory hash. Frequency validity requires f<0.4*native_sample_rate and finite nonzero transfer. All response fields become zero with explicit valid=0 for unknown or inconsistent chains, reported-vs-computed sensitivity discrepancy >5% at the stated calibration frequency, stage-unit/rate discontinuity, invalid stage numbering, or inconsistent final/native sample rates. Stage gains are not silently renormalized by our code; evalresp's own documented normalizations/warnings are retained in the audit. No calibration repair from waveforms or labels.

For response continuous coordinates, fit weighted means/stds using only valid fitting-record coordinates, then reapply zero at invalid coordinates. Never turn masked zeros into measured flat response. Leave response validity masks as0/1. Fit static normalizers on selected fitting metadata; fit per-deadline amplitude normalizers on fitting rows valid at that deadline. Scale floor1e−6 for fitted standard deviations; clip normalized continuous metadata/amplitude inputs to±8. Every fitted statistic uses original restoration weights and is saved. No held-event statistics, histogram or label information enters preprocessing. The normalized waveform path uses prefix-local RMS only, no fitted population waveform scale.

## Four fixed arms, all active capacities matched

A is counts-late; B is native-late; C is native-conditioned; D is counts-late with coherent digital-gain augmentation. All have the same fresh compact independent encoder/GRU/66-bin head, the same106 late metadata inputs (34+72), and the same conditioning MLP. No new amplitude branch, hidden teacher or residual correction to old logits.

Conditioner input is72 response fields plus21 nongain fields from the component-response portion of the34 static fields: units, missingness, calibration frequency and native sample rate. Exclude the three absolute-gain values and all site/family fields from this MLP. The common late metadata path still retains all34 fields, including gain; therefore the **whole model is not claimed structurally gain invariant**.

Conditioner architecture: Linear93→32, SiLU, Linear32→256. Split output into128-vectors a,b. Set γ=1+0.5*tanh(a), β=0.5*tanh(b). Initialize the final layer exactly zero, so γ=1,β=0. Let z be the last128-channel residual-addition output before final SiLU σ; pool concatenates channelwise mean/max. A/B/D use γ*pool(σ(z))+β, applying the same pair to each pooled vector. C uses pool(σ(γ*z+β)). Both have identical active parameter counts and exactly identical B/C initialization outputs; they differ only in modulation placement. Do not move modulation after σ but before pooling: that would commute with mean/max pooling for positive γ and produce a duplicate control.

Concatenate pooled256, amplitudes6, duration1, and late metadata106, then the same Linear369→128/LayerNorm/SiLU, GRUCell128/reset-at-each-deadline and Linear128→66 decoder. Expected capacity is380,706 trainable parameters: existing355,682 +13,568 expanded projection +11,456 conditioner. Verify this count and paired initialization in tests before implementation is accepted. Independent prefixes share weights but no recurrent state across deadlines. Expose an explicit single-prefix forward function so supplying1s never computes/reads a later suffix.

D uses one fixed digital re-expression per training record/epoch/component: log10(c) uniform[−1,1], determined from an independent stateless seed/epoch/source-row/component stream. Use the same c across deadlines of that record. Transform q→c*q, g→c*g, H→c*H before log-amplitude/static normalization, with unchanged magnitude. H/g, unit, sampling rate and calibration frequency remain unchanged. Do not multiply source amplitude while leaving gain fixed; do not resample clocks. D uses A's original fit-only normalizers, initialized weights, model/dropout and sample-order streams. The separate augmentation stream never advances them. Quantization/clipping/sensor saturation are not simulated. No redundant canonical-native augmentation arm is added.

## Fit, evaluation and decision

Exactly8 training runs:4arms×seeds20261009/20261010; each run jointly learns1/3/5s,10epochs. Batch512, AdamWlr3e−4, decay1e−4, cosine to3e−5, gradient clip5. Same fit records, restoration weights, initialization, deadline batching, steps and deterministic CUDA flags. No early stopping, sweep, seed selection or validation-chosen loss. Set `CUBLAS_WORKSPACE_CONFIG=:4096:8` before CUDA initialization and `torch.use_deterministic_algorithms(True)`; record cuDNN/TF32/library versions. If unsupported deterministic operations occur, stop rather than relaxing determinism.

Use the existing supervised objective averaged equally over deadlines: `(1+5*max(y−3.5,0))*Huber_delta1(E[M],y) + .075*CE(logits,clamp(floor(y/.1+1e−5),0,65))`, using the exact existing target/bin definitions. Original inverse recording-sampling weights restore the metadata-sampled population; do not add a second inverse factor. Each deadline's finite population and weight normalization are independent. A training step draws a batch from each deadline's valid fitting population using an ordinary seeded permutation/cycle, with D=max_t N_t draws per deadline per epoch, so three horizons have equal exposure. Each deadline contribution is its weighted-loss mean using weights normalized over that deadline's entire fit population; batches have equal draw counts and a common final remainder. All arms use saved identical order digests. Smaller populations cycle their shuffled permutation; this fixed scheduling is not target-driven. Invalid later suffixes never remove earlier rows. Report this departure from old same-row/all-prefix training. No sequential/entropy/growth/proper-score auxiliary is added.

Primary contrast is **C−B**. A−B identifies ordinary unit preprocessing; D−A identifies ordinary augmentation; any of those may be useful baseline findings without supporting the encoder mechanism. Report both individual seeds and the mean-probability ensemble at all deadlines; mean and median decisions; MAE, MedAE, event-macro MAE, M≥4/M≥5 MAE/bias, individual tail-event deltas, CVaR95, NLL/continuous-label CRPS and calibration. The weighted Huber objective is not a proper density score overall. Evaluate coherent-gain re-expression sensitivity as a diagnostic, not an invariance guarantee.

For a primary pass, in **both seeds, at every1/3/5deadline and in both held-event/seen-station and joint-held-event/held-station subsets**, C−B must have: all-record magnitude MAE ≤0.002; MedAE ≤0.002; M≥4 weighted-record MAE <0; and M≥4 unweighted event-macro MAE <0. Require at least20 M≥4 events in each evaluated subset. Use1,000 fixed paired event bootstrap replicates, seed20261011, retaining record weights and pairing arms. For an uncertainty-supported pass, require ensemble upper95% bounds ≤0.002 for bulk MAE/MedAE changes and <0 for both tail MAE changes, at all deadlines/subsets. Station dependence remains a limitation; this stringent exploratory investment gate is not a familywise confirmatory test. If any required support or precision is insufficient, report inconclusive rather than loosening the gate.

If C passes, its narrow mechanism still needs a later scalar/unit-only versus full-response-shape conditioning ablation and external sensor/unit transfer. An improvement confined to seen stations or matched by D is not proof that nominal frequency-response information helps. No exact novelty or published SOTA claim follows from this pilot. Fixed66-bin support does not establish M7–9 extrapolation.
