# Fixed architecture grid entry point

`train_response_grid.py` implements the frozen A/B/C/D architecture protocol, distinct from the separately reviewed CE exposure controls. It uses the exact weighted Huber(delta1,beta5,threshold3.5)+0.075CE objective. Restoration weights are divided by the mean weight over the entire valid fitting population for that deadline; the batch loss divides by draw count, never by the batch sum of weights. Three deadline losses contribute equally to one optimizer step. The cosine schedule advances once per epoch, matching the existing independent baseline convention.

All four arms use the same model initialization, target-free epoch/deadline permutation cycles and draw counts for each seed. A smaller valid population cycles independently until the maximum deadline population size is reached. D's stateless gain augmentation does not advance model or order RNG. Original fitting and held-event data come only from the completed shared export; there is no DEV, VAL or TEST argument. The final ten-epoch model is saved and evaluated once; there is no held-panel selection.

The CLI is dry-run by default and reads no source/data files until `--execute`. After the parent has authorized the reviewed export, use the current immutable `training_source_manifest.json` and its separately verified SHA:

```text
python train_response_grid.py --export <completed-export> --bundle training_source_manifest.json --bundle-sha256 <sha> --output <new-directory> --execute
```

Only the parent launches this command on the existing worker. The top-level process fits and saves shared fit-only normalizers once. It invokes eight fixed children (A/B/C/D, seeds20261009/20261010), each with a600-second subprocess timeout and a4800-second total training-stage budget. Each child uses exactly10epochs, batch512, AdamW3e-4/1e-4, epoch cosine to3e-5, clip5, strict deterministic CUDA and disabled TF32. Unsupported deterministic operations terminate the run. A separate CPU report stage has a1800-second timeout. A timeout/failure leaves incomplete status and no completion marker; no automatic epoch or dataset reduction, partial-grid analysis, checkpoint selection, or resumption is supported.

Each run records source/protocol/export/normalizer identities; library/GPU/deterministic settings; initial/final state hashes; exact per-epoch/deadline order hashes; fitting populations and weight means; losses/steps; checkpoint; all six held-panel probabilities with exact row arrays; and coherent-gain sensitivity diagnostics. A completion marker binds its final manifest and artifact hashes. The final report refuses missing runs, changed arrays, misaligned probabilities, inconsistent initializations or normalizers, incorrect fitting populations, incomplete histories or incorrect order/step counts. Predictions use float64 softmax for finite accurate PMFs, while training remains float32.

The report includes both individual seeds and equal-probability ensembles for mean and median actions; continuous-label CRPS, clipped-category NLL, coverage and tail calibration; record-weighted bulk/tail error, event-macro error, CVaR95 and individual events; unit/family/station groups; lost-event/validity counts; and held-event comparisons restricted to events shared between seen/held station panels. The primary C-minus-B gate is exactly the frozen all-deadline/all-subset/both-seed gate, with1000 paired event bootstrap replicates, seed20261011, including weighted MedAE. Tail intervals resample the observed M>=4 event population conditionally; station dependence and multiple comparisons remain limitations. Insufficient20-event tail support or validity<90% is `inconclusive_support`. When both-seed effect thresholds pass but bootstrap bounds do not, the status is `inconclusive_precision`, not an observed-effect failure. No method novelty or published superiority claim is inferred.

Synthetic tests use invented records only. They exercise exact loss arithmetic, schedule/RNG isolation, fitting-only provenance, all-arm initial state/order equality, deterministic CPU repeats unaffected by held targets, full eight-run report/artifact guards, PMF CRPS/CVaR, bootstrap and gate logic. Production runs remain the parent's responsibility after clean isolated review.
