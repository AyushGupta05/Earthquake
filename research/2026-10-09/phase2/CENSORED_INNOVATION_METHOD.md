# Sequential block-peak likelihood pilot

This is an implemented **module, artifact adapter and fixed training runner**, with CPU fixture tests. No actual earthquake training run has been executed for this pilot yet. There is no new 1 s prediction: all arms start from the same existing one-second instrument-static residual for a given seed. No novelty, calibrated-Bayes, rupture-survival, extrapolation, or state-of-the-art claim is made. The purpose is to test an incremental observation model, and whether censoring helps or merely discards information.

The research proposal is `work/instrument_research/next_method_candidates.md`. Relevant primary prior art includes [RTMag, Lancieri & Zollo 2008](https://doi.org/10.1029/2007JB005386), [Trugman et al. 2019](https://doi.org/10.1029/2018JB017093), [Münchmeyer, Leser & Tilmann 2022](https://doi.org/10.1029/2022GL098344), and [Tobin 1958](https://doi.org/10.2307/1907382). Posterior recursion, saturation-aware magnitude likelihoods, and censoring are established ideas. This pilot tests a specific observation map and constrained likelihood.

## Observations and deadlines

Use the vertical component of the released INSTANCE **counts**, aligned to the existing benchmark manual P pick at 100 Hz. Component order is ENZ; vertical is index 2. Subtract one fixed baseline: the mean of samples `[0:10]`, the first **0.1 s after P**. This differs from the memo's initially proposed pre-P baseline and requires no pre-P data. The baseline is unchanged at every deadline. Divide by the matched positive epoch sensitivity; preserve whether the native input unit is velocity or acceleration in H1's static fields. This is scalar gain correction, not response deconvolution.

Define native-unit absolute peaks `A1=max(abs(u[0:100]))`, `B13=max(abs(u[100:300]))`, `A3=max(A1,B13)`, `B35=max(abs(u[300:500]))`. Observations are `Z13=log10(B13)-log10(A1)` and `Z35=log10(B35)-log10(A3)`. `G=max(0,Z)` is the record-peak increase. There is **no tolerance around zero**: exact nonpositive Z maps to the atom, positive G is treated as a continuous observation.

The default `1e-12` native-unit floor is a numerical floor, not a measured noise threshold; its physical dimension follows the velocity/acceleration input unit. Both compared peaks must exceed it, with finite samples and usable response/unit metadata. The same masks apply to every arm, including uncensored Z. When step 13 is invalid, step 35 is skipped too. This conservatively avoids inventing a negative ratio from a floored peak or a missing history. A censored-only method could retain more zero observations, but this pilot deliberately does not grant it a different sample population. Mask/floor occurrence itself may be informative; **that selection information is ignored rather than claimed to be Bayesian evidence**. Report validity rates by magnitude/family/deadline. Unknown gains/units generate zero placeholders with false masks. Incomplete blocks are unavailable: a 300-sample input produces the 13 mark only. Samples beyond 499 are never inspected.

Digital re-expression `(counts, baseline, sensitivity)→c*(counts, baseline, sensitivity)`, `c>0`, leaves the native signal and ratios invariant numerically. The ratios also cancel scalar sensitivity away from the floor. This does not remove frequency-response differences, and it does not make acceleration and velocity physically interchangeable. H1 still includes the old counts-based network and gain/site descriptors: **the full model is not gain invariant**. The test concerns the new observation map only.

`undo_count_standardization` inverts the exact saved float32 affine transform, including its float32 `std+1e-8`. Its output still has cache-rounding error. Prefer direct raw-count prefix reads where practical. Neither helper reverses INSTANCE's original full-record preprocessing or manual-pick timing; the separate causal-preprocessing audit remains applicable.

## Five learned arms and frozen control

The retained context H1 is the existing normalized 291-column one-second design, with its last 12 native-summary inputs masked to zero exactly as in the `instrument` static arm. Its active 279 values comprise the frozen logits, waveform hidden state, prefix descriptors, and 34 static response/site features. H1 is frozen. At step 35 the generative conditional sees only H1, candidate magnitude, the earlier **observed** G13 (Z13 in the uncensored arm), and a step indicator. It never sees a full three-second hidden state, logits, prefix summaries, or newly recomputed normalization.

| Arm | New evidence | Conditional model / training objective |
|---|---|---|
| Frozen start | None | Repeat the exact p1 at 3/5 s; no fitted parameters |
| Censored | G13 then G35 | Latent `Z~Normal(mu,sigma²)`: atom `Phi(-mu/sigma)` at G=0 and ordinary normal density at positive G; labelled conditional NLL |
| Free hurdle | G13 then G35 | Independent learned zero-atom logit and lognormal positive density; labelled conditional NLL |
| Free truncated-Gaussian hurdle | G13 then G35 | Free zero-atom logit; positive normal density divided by `Phi(mu/sigma)`, the exact positive conditional family of the censored arm; labelled conditional NLL |
| Uncensored | Z13 then Z35 | Normal density on the whole real line, retaining sub-record motion; labelled conditional NLL |
| Discriminative | G13 then G35 | Sequential bounded log-odds residual using H1, earlier G, and current G; categorical NLL of updated magnitude predictions |

For generative arms, `log p_b = log p_a + log q(new mark|m,H_a) - logsumexp(...)`. Invalid marks leave p unchanged. A zero mark can be informative through different atom probabilities; a magnitude-independent likelihood leaves p unchanged. The model uses sigma `softplus(raw_scale)+.03`; all likelihoods, `log_ndtr` atom values and posterior arithmetic are float64. Positive densities may exceed one without violating normalization. Values are not clipped into probability masses. Data precision creates another approximation: no explicit quantization-bin likelihood is implemented.

The shared head shape is `[H1 + candidate magnitude + earlier mark + current mark + two step indicators] → 64 SiLU → 32 SiLU → 3`. All learned arms have exactly the same allocated parameter count and seeded tensors; the final layer starts at zero, so all initially reproduce p1. The current-mark input is zeroed for generative conditionals and active only for the direct control. The third output is inactive for the censored and uncensored Gaussian arms; only output zero is active for direct log-odds corrections. Consequently **active capacity and output meaning differ**, despite identical allocated counts/initialization. The frozen control has no fitted parameters. The direct correction is `5*tanh(output/5)` at each update; its NLL objective differs from the generative observation NLL. These differences must be reported, not hidden as “identical models.”

At step 35, G13 is the earlier mark in all four censored-input arms. Negative Z13 changes neither their earlier posterior nor their retained history. The uncensored arm retains Z13 and therefore has genuinely more information. A gain for uncensored Z over censored G weakens the rationale for censoring. A gain for the free truncated-Gaussian hurdle challenges the CDF tie while preserving its positive conditional density family; the lognormal hurdle additionally changes density shape; a same-input direct head matching the tied likelihood weakens the case that the recursion matters.

## Fixed fit protocol

- The runner sets `CUBLAS_WORKSPACE_CONFIG=:4096:8` before CUDA initialization, enables deterministic algorithms with errors on unsupported operations, sets cuDNN deterministic and disables benchmarking. It preserves and records existing TF32 flags to avoid silently changing frozen-backbone arithmetic.
- Seeds: 20261009 and 20261010; 15 fixed final epochs, batch 2048, AdamW learning rate 5e-4, weight decay 1e-4, gradient norm cap 5. No validation argument exists in `fit_arm`.
- Use the exact existing 197,676 selected TRAIN recordings (all M≥4 recordings plus max-four-per-event selection) and existing positive inverse-sampling population weights. Preserve row/event/trace identity. The weights restore record frequency, not an event-uniform population; normalize their TRAIN mean to one.
- Label the magnitude grid exactly as the existing distribution model: `(y/.1 + 1e-5).floor().clamp(0,65)` with 66 centers `(arange(66)+.5)*.1`. Generative training conditions on the target **bin center**, consistently with evaluation on this grid. This is not continuous-label density fitting or high-M extrapolation.
- Generative loss averages the two masked conditional NLLs per record, then takes the weighted minibatch mean. Direct loss analogously averages categorical NLLs at valid 3/5 updates. All-record denominators are fixed; missing observations contribute zero rather than altering per-batch denominators. Row-order hashes are saved by the trainer. The direct model uses ordinary CE, not an extra beta=5 tail loss.
- The initial static p1 was trained with beta=5 weighted Huber + .075CE, not a proper-score-only objective. It is cost-sensitive and may be miscalibrated. Normalization of a likelihood update does **not** repair this or establish a true posterior. The frozen predictor was trained on these TRAIN labels; this is a training-set plug-in study, not cross-fitted calibrated Bayesian inference.
- Report the exact identical 1 s p1, all seeds/arms at 3/5 s, and the existing full-prefix static 3/5 networks as stronger-information references. No model/epoch/threshold/blend is selected using reused VAL. There are only 13 M≥4 VAL events, one M5.1 and no M≥6; inference about large ruptures is unsupported.

## Artifact adapter and implemented runner

`load_frozen_start(data, identities, instrument_names, run_directory, seed)` accepts the return of the existing `instrument_residual.extract` with `seconds=1`. It checks the fixed 1 s/beta5/15-epoch/static configuration, exact TRAIN rows/events/traces/weights, source metadata/normalization/inventory/backbone identities, feature schema and normalizer/mask. It replays the saved VAL probabilities and returns frozen TRAIN/VAL H1 arrays, normalized log p1, and SHA256 provenance. It never silently retrains a different start.

The AWS artifact is `/mnt/eew-research/runs/instrument_residual_1s_1bbf4f4d67e5_2b94eb7e7f00`. The runner pins both inspected checkpoint hashes:

- `instrument_seed20261009.pth`: `d53f7ecfdf24cefb02382d29cac4c9d79a6ba17c683933d14757a8df66249c70`.
- `instrument_seed20261010.pth`: `78b6b6f86344dc7acb1383e77fe234f8994dfb46230fcd1c7f2727c995db1d8e`.

`train_censored_innovation.py` implements these operations:

1. Extract only the one-second backbone and require the exact 197,676 TRAIN rows. Read TRAIN and reused VAL only. There is no TEST/split-selection option and no 3/5 s network extraction.
2. Verify metadata, inventory and count-normalization hashes. For every selected TRAIN and all VAL rows, require the cached five-second target/order and first100samples to agree with the corresponding one-second cache. Then check **all500samples, all3components** against the named raw trace at its exact P pick under the audited float32 normalizer. This is exhaustive selected-row identity verification rather than label-only or sampled validation. HDF5 size/mtime is recorded and checked for changes during extraction; HDF5 files are not fully hashed. An incorrect raw length or missing trace fails instead of being padded.
3. Rejoin the pinned inventory using those exact metadata rows, compare all34static features against the one-second extraction, and use the original float64 Z sensitivity and matched response mask. Read units by explicit `Z_velocity`/`Z_acceleration` names; ambiguous flags fail. Invert the cached affine transform and form the fixed-first-ten-sample observations. No catalogue distance, magnitude-type input, final amplitude/SNR, or later waveform embedding is added.
4. Save Z/G, valid masks, floor diagnostics, sensitivity/unit fields, row/event/trace/target identities and reporting-only station/family fields. Invalid values remain zero placeholders with separate bitmask reasons: unusable response, bad sensitivity, unknown unit, previous/new floor or nonfinite peak, and unavailable earlier update. Reason flags may overlap. Unknown/floored cases are not invented physical observations.
5. Replay **both** pinned one-second checkpoints, including their stored VAL probability arrays, before fitting any arm. Save exact log p1 for TRAIN and VAL and common H1. `--prepare-only` exits at this point without a fit. This option is a diagnostic; a later ordinary run repeats preparation rather than trusting an unverified cache.
6. Fit all five learned arms with both fixed seeds and final15epochs, plus the frozen control, with no validation selection. Defaults for epochs and seeds are fixed in the parser. The positive truncated-Gaussian control has `q(0)=sigmoid(a)` and `q(g>0)=(1-sigmoid(a))*normal_pdf(g)/Phi(mu/sigma)`. Setting its atom logit to `logPhi(-mu/sigma)-logPhi(mu/sigma)` recovers the censored model exactly; a test checks this identity.
7. Save each model, row-order history, all per-seed/per-deadline float64 probabilities and mean/median predictions, probability ensembles, configuration, sources and input hashes, parameter allocations, raw observations/masks and source identities. Ensemble averaging happens after each seed's sequential update. There are21,187allocated parameters per learned arm at291H1inputs; the frozen control fits none. Every final artifact is hashed in `artifacts.json`.
8. Save held-VAL conditional observation NLL, forecast-mixture NLL, predicted zero probability, and positive PIT with explicit validity masks. Uncensored-Z NLL lives on a different sample space and is not numerically ranked against censored-G NLL. Mean/median magnitude metrics include bulk MAE/MedAE/CVaR95, event-macro and M≥4 errors, threshold confusion counts, CRPS and Brier. Event-bootstrap intervals, event/family breakdowns and comparison with the full-prefix3/5static references are subsequent analysis of these identity-preserving artifacts, not automatic claims made by this runner.

The prepared-only and full run paths are exercised by small CPU fixtures. **Actual full-data probability replay and training have not run for this pilot yet**; real replay must pass at runtime before fitting. Source checkpoints' schemas/hashes were inspected read-only on AWS Torch2.8.0. No live GPU training job was launched during development. A read-only CPU probe of eight TRAIN and eight VAL records verified every named raw500sample prefix. However, the old GPU checkpoint replay on those eight VAL records differed from saved probabilities by `1.2046504e-4` and `1.1309958e-4` for the two seeds, failing the adapter tolerance. This CPU probe is **not** an accepted starting replay. The follow-up original-GPU inference-only probe on the first2048VAL rows used the original backbone batch256 and residual batch2048, the saved normalizer, A10G hardware and preserved TF32 settings. Both nondeterministic-mode and deterministic-mode backbone logits matched exactly; both seeds reproduced saved probabilities within `1.46e-8`, consistent with the float32 reference archive. That probe finished in9.93s without optimization. It supports retaining the original checkpoint pins and strict tolerance. Full selected-TRAIN/all-VAL replay remains the enforced runtime gate before fitting; no tolerance was relaxed. Probe reports are `work/instrument_research/censored_innovation_integration_probe.json` and `censored_innovation_cuda_probe.json`.

Adding `--prepare-only` verifies/persists input observations and both starting predictors without head training. It still performs network feature extraction on the specified device. A CPU invocation uses `--device cpu` and `CUDA_VISIBLE_DEVICES=""`. Development used CPU synthetic tests plus the explicitly authorized bounded original-GPU inference probe; this full-data training command has not run. A conservative `timeout 3h` wrapper can bound the first pilot; the full raw-HDF verification/serialization runtime has not been measured, so this is a cap rather than an ETA. Observation progress is printed every16384rows and completion is printed per arm.

Passing tests establishes observation, identity and numerical contracts, not forecasting benefit. Before promotion, require the prespecified bulk-error constraint and tail improvements against the stronger static references, both deadlines and both seeds. Reused VAL remains exploratory and TEST stays sealed until a protocol is frozen. No claim of full-model gain invariance, proper Bayesian calibration or large-magnitude extrapolation is supported.
