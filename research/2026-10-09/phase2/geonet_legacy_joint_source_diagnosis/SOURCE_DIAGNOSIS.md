# Frozen adapter V1 source-only failure diagnosis

The reported actual child failure remains **unknown**. No actual plan,
authorization, event body, output or receipt was read in this audit. A source
integration failure was not reproduced by nine invented six-event cohorts using
the exact frozen producer V2 and independent semantic V3 implementations.

The probes verified all 86 producer and 34 auditor public source members through
V1's source-bundle reader, then compiled the four already verified source buffers
through V1's real loader. They used no scientific interface stubs. One cohort also
completed through the real supervisor, start gate, fresh `-I -B` child,
serialization, bounded output handling, group termination and receipt path.
Invented authorization assertions and digests existed only inside temporary
fixture directories; they are not actual execution authority. Temporary fixtures
and outputs were removed after extracting aggregate evidence.

Each cohort had six distinct invented event/origin/pick identities, three separate
body files per event, null parent native-profile requests, one SCML 0.10 root and
five SCML 0.11 roots. Plain QML used the corresponding mapped IDs. Baseline origin
time was Unix epoch, latitude -40, longitude 175 and equivalent depth 10 km/10000 m;
its one NZ/FAKE station pick arrived at epoch, with P phase and positive weight 1.

## Separate, nonfatal null-anchor reporting mismatch

When the original T0 is null and the known accepted pick subset is identical,
the producer reports `at_preserved_original_T0: null`. V1's independent clock
helper instead reports a dictionary with `anchor_us: null` and null horizon
counts. The adapter compares entire dictionaries, so this invented six-event
cohort flags 18 clock mismatches although the independently reconstructed own
clocks agree. The invocation still completes; therefore this defect does **not**
reproduce or explain the reported actual child failure. It must not be silently
patched into the first-clean V1. Any approved correction needs a separate version
and a real-module invented regression.

source pins. `v1_preservation_check.json` verifies all 136 original manifest members
against the immutable V1 manifest, with zero mismatches. V1, producer V2 and auditor
V3 were not changed. No requests, paid work, fitting, shared Git changes or actual
invocation were performed. This audit added documents/aggregate evidence only;
it did not create a new production runner or rerun the already-clean V1 review.
