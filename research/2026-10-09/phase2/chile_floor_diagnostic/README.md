It tests the frozen gate in `diagnostic_protocol_v1.json` (SHA256 `f36836e562b07baa740b8d8219d2063f369f92fb27be3f4d95efab1ac5757b48`). `protocol_amendment.json` records pre-data clarifications: the existing **calibration-NLL-selected** checkpoint is accepted only after all 25 station/100 event epochs finish, and the launch budget is tightened from 1800 to **600 seconds**. The v2 amendment corrects the completion guards to the actual frozen launch: `skip_dev=False`, `dev_evaluated=True`, `selection_used_dev=False`, `test_reads=0`. The baseline reports DEV after its TRAIN-calibration selection; this diagnostic never uses those DEV scores or performs DEV forwards. The previous amendment and source pins remain archived as `*_pre_dev_flag_correction.json`.

For Gaussian-mixture density p and epsilon=1e-6, the output gradient of -log(p+epsilon) is p/(p+epsilon) times the gradient of -log(p). Gaussian log responsibilities and entropy distinguish component responsibility concentration from this event-wide attenuation. Results include derivatives with respect to pre-softmax logits and post-ReLU means/scales (also log-scales). They exclude head ReLU Jacobians, neural parameter gradients, clipping, and optimization history. The hypothetical normalized Huber-mixture score uses delta=2 and matches each Gaussian component's mean/variance; it changes responsibilities as well as tail scores. This is established robust-density mathematics, not a novelty claim. No Huber head or fitting code is present.

Only TRAIN **fit** events enter model forwards: all MA>=5.5 plus up to 1024 per prespecified lower-magnitude stratum, selected by the frozen event hash. The exact saved split manifest is bound to checkpoint/run source-ID digests. The 55,053 logged training draws are not 55,053 unique fit events: resampling does not change diagnostic membership. Histories are pinned and only their epoch sequences are retained/consulted. No calibration score or DEV/TEST result is used. Non-fit sidecar rows are checked only for event/source-row/split identities; their labels/times are not parsed. Whole-file SHA verification necessarily reads all cache bytes, without decoding non-fit waveform samples. HDF group names/split ID arrays are integrity metadata.

The source EventDataset, collator and TeamLM forward are imported only after exact source verification. Dataset evaluation is ordered, unaugmented, and has zero workers. If any selected event would exceed the saved station cap, fail rather than truncate it. The deadline is measured relative to **network-first P**, with five seconds of pre-P input: 1/3/5 s expose exactly 600/800/1000 samples at 100 Hz. Each selected fit container is loaded using the source evaluation path; strict-prefix masking/demeaning occurs before all model paths. This reproduces the reviewed causal boundary correction, not unverified original-release preprocessing causality.

The gate uses the original evaluation point mean/median calculated from native float32 softmax weights cast to double. Normalized log-domain density mathematics recomputes log-softmax from double-cast logits; both weight versions and their tiny rounding discrepancy are saved. Original mean and median errors use prediction minus true MA; underestimation is true MA minus mean. No alternate point decision is selected.
