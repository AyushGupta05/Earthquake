# Independent raw replay method

The replay was a separate one-off local Python analysis using public ObsPy read/read_inventory/response APIs, NumPy, fractions, hashlib and JSON. It did not import audit.py/core.py, fetch another response, fit a model, merge/fill/filter samples or invert an instrument response. The source and frozen plan remained unchanged after clean review.

The parent reported collection exit0 before replay. Analysis required completed=true and absent outer/process failure markers. It verified the committed code/protocol against actual Git objects, private plan/parent receipt/dependency hashes, pinned census input hashes, every manifest member's size/SHA and every raw response body's size/SHA. Attempt order was rebuilt from the frozen paired queries, allowing only skipped waveform after non-successful StationXML. For each decoded target, inventory identity/epoch restriction preceded numeric validation. Effective epochs used maximum network/station/channel start and minimum end, while preserving a separate required channel-start flag. Unique coherent ENZ/12Z triplets had to span each entire strict prebuffer/prefix, with valid common rate/orientation. DEF evalresp at the stated sensitivity frequency reconstructed transfer metadata and Python warnings directly; the independent result was compared field-for-field with saved response evidence. Physical calibration remained false.

Native sample times were explicitly enumerated as exact fractions from each trace's nanosecond start and recorded rate. Only times in[T0-5,T0+1/3/5)were retained, so this did not use production ceil/crop helpers. A nearest-integer period-distance calculation independently rebuilt within/cross-component lattice checks. Strict edge coverage, fragment gap/overlap checks, finite samples, metadata values, flatline and repeated prefix-extreme runs were compared field-for-field. Runs crossed contiguous same-rate fragment boundaries. No data was filled or re-timed. Actual future samples were replaced with NaN at each audited deadline, with no change to any reconstructed component evidence.
