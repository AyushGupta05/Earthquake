# Matched controls and scientific gates

Prior information in EEW is established prior art. [Cua and Heaton's Virtual Seismologist](https://www.its.caltech.edu/~heatont/papers/VSmethod_cua_heaton%20%282%29.pdf) combines uncertain magnitude/location with waveform likelihoods and background seismicity, faults, GR and network information. [Cua et al. 2009](https://authors.library.caltech.edu/records/w1e0t-ra376) describes evolving real-time estimates. [Lancieri and Zollo 2008](https://agupubs.onlinelibrary.wiley.com/doi/abs/10.1029/2007JB005386) develops evolutionary Bayesian magnitude inference from early P/S displacement. [Wu et al. 2015](https://authors.library.caltech.edu/records/0cdjs-00z18) estimates magnitude, hypocenter and origin time under multi-event Bayesian inference. These primary sources make a broad claim of inventing Bayesian priors, sequential probability updates or latent-source marginalization untenable. MAGNET's history-conditioned density is already documented in the separate capsule. Combining known components alone is not an established novelty claim.

The prospective contribution would have to be a demonstrated, publication-aware history adapter with a defensible waveform-prior correction and source uncertainty, improving matched 1/3/5-second outcomes. That claim still needs a wider primary-literature search for closely matched catalog-plus-waveform EEW implementations and an independently sealed experiment. A density-family change, entropy gate, prior multiplication or better likelihood alone is insufficient.

All arms below need identical target IDs and label scales, chronological and sequence-aware split rules, strict absolute clocks, actually arrived stations, waveform preprocessing/response choices, quality/missingness denominators, train budget, architecture capacity where relevant, seed pairing and frozen tuning allowance. Reuse exactly the same frozen waveform weights for posthoc arms. Fit/catalog normalization/completeness thresholds on permitted training histories only. Histories must obey the same as-of-publication rules in training and evaluation.

| Fixed background at first trigger versus deadline-specific publication updates | Does catalog arrival during the prefix help, and does association leakage explain it? |
| Joint W,H refit with matched capacity and tuning budget | Is a learned fusion model better than posthoc prior correction? Keep the different modeling claim explicit. |
| Alternative density head/support, fixed alpha grid, ratios/entropy safeguards | Separate history information from distribution flexibility and protective heuristics. Use the same variants on simple-prior controls. |

Report paired mean- and median-action MAE/MedAE/bias, CVaR95/P95/max absolute error at every horizon, plus magnitude bands >=5.5, >=6 and >=7 with their exact denominators and all individual rare-event errors kept privately. Add NLL, CRPS, probability calibration/PIT and threshold Brier/reliability. Completeness-conditioned catalog likelihood is a separate endpoint on an explicitly defined subset; it cannot replace full-denominator EEW error or suppress difficult events. State all observed worst-error regressions and all missing/unknown history/waveform cases.

Select no arm from TEST. Freeze bulk noninferiority margins and both-seed consistency requirements before any fit/selection, using the current authorized protocol's margins only if the parent explicitly adopts them for this new population. Freeze primary tail thresholds and a worst-error guard as well as an improvement criterion; successful bulk MAE does not justify a worsened extreme miss. Use paired resampling that respects earthquake sequences/time blocks and a sensitivity analysis to dependent records, not an independence claim from event bootstrap alone. Effective number of independent high-magnitude sequences must support the intended confidence claim; sparse descriptive case improvements cannot demonstrate generalization. Gains in density at observed magnitudes need not move the mean/median or improve either error tail.
