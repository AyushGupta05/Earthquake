# Independent native-count auditor contract

This is code-only preparation against the immutable producer protocol/checklist. No actual outputs, raw bodies, private selection/acquisition plans, cache members or receipts were read during construction or tests. Public producer source was read for the frozen contract; no production helper was copied/imported/executed. The independent implementation uses direct standard-library XML epoch math, integer-nanosecond timestamps, rational sample bounds, streaming two-pass sample diagnostics, and public ObsPy miniSEED/read_inventory/evalresp primitives.

Source and tests stop changing at the first clean default Codex autoreview. Actual replay remains unavailable until a separate completed parent handoff. No installed dependency, request, retry, replacement, resume, filter, rotation, resample, deconvolution, training or AWS action is part of this library. Its only native tests encode/decode invented data in temporary files.

## Implemented checks

- `select96`: fixed60+30+6 allocation, metadata-independent hash rank, original accepted-subset T0, station-collapse ties, strict1/3/5 deadlines and cap8; preserves no-P/unknown source events. Default lower-frame hash is frozen; the alternate hash argument exists to test invented complete frames and must not replace the frozen hash in an actual replay.
- `query_contract`, `exact_cache_match`: literal location/prefix/envelope and six <=16-event ASCII POST bodies, channel GETs unaffected by cache/sample qualification, exact successful original GET selections with body/member/request pins. Broader windows, response-versus-channel levels and partial failures never become hits.
- `verify_completed_files`, `verify_attempts`: completed exit0/no markers, explicit terminal status set with timeout/resource diagnostics and native/wrapped resource errno messages rejected, bounded nonsymlink members, raw/ledger hashes, request order, POST bodies, attempt/body/deadline/spacing caps and partial sidecars. The finite recorded launch duration must encompass every recorded attempt. Ordinary network OSError outcomes remain ordinary failures. Incomplete artifacts are rejected before decoding. Generated member bodies over32MiB reject replay rather than being loaded unboundedly; no scientific absence is inferred.
- `stationxml`, `epoch_triplet`: bounded UTF8/no DTD/entity/NUL, direct network/station/channel intersection, known channel start, uniquely concurrent epoch spanning prebuffer/deadline, ENZ before12Z without sample-dependent fallback, same rate and declared orientation. Selected dip must lie within[-90,90] and azimuth within[0,360] before tolerance checks. Individual network/station/channel dates remain separate from their coverage intersection and participate in the exact response join. An otherwise bounded retrieved XML body with the wrong root is an ordinary target-local metadata failure. Invalid and overflowing timestamps remain per-epoch errors; valid known bounds can exclude wholly future/past epochs before checking their errors. Entirely future rate/orientation is not consulted earlier.
- `prefix_component`, `aligned`: exact native rational strict-right cropping, edges, fragment gaps/overlaps, rates/lattices, finite samples, fragment-invariant flat/extreme runs>=8 and timing/calibration metadata. Public ObsPy decoding preserves each miniSEED2 record separately; direct FSDH factor/multiplier clock fields or the exact Blockette100 binary float define the sample period. Rounded floating decoder rates never define an actual native crop. Synthetic array fixtures may use their explicitly supplied decimal rate. No concatenate/merge/fill operation alters samples. Count-valid, clean-screen and physical-unclipping claims remain separate.
- `BlockDecoder`: bounded public header-first decode, at most one new body plus9 cache candidates, declared npts×8 and cumulative actual ndarray bytes sharing64MiB per block, repeated pin reads, resource interruptions from headers/declarations/decoding propagated. Ordinary bad new headers/decoding do not erase valid independent caches; cached failures never select fresh-byte fallback. Native record clock support here is miniSEED2 data records; full SEED, miniSEED3 and unsupported/truncated record forms fail ordinary decoding without recovery or substitution. Caller releases its streams between blocks; this object retains no decoded arrays.
- `selected_response_xml`, `response_panel`: optional exact cached selected epoch/rate/orientation join, deterministic pruning before public response parsing, sensitivity/units/stages checks, public DEF evalresp, Python and bounded native stderr warnings, finite nonzero transfer. Only the selected containers and complete response stages reach public parsing; original bytes/pins remain provenance. Channel-only metadata never proves full response; ordinary response failures do not erase counts and physical calibration remains false. Body-cap/provenance errors, memory and resource-related OS failures propagate as incomplete replay.
- `qualify`, `qualification_batch`, `aggregate`, `compare_prefix_facts`: each target×3, every96×3 source event, current station views only, horizon/common support, band/calendar panels and semantic sample/response comparisons including captured native warnings. Horizon/response physical-calibration and horizon operational-picker flags are compared, retaining missing-versus-present differences. Extra independent stage statuses and public counters distinguish retrieval/header/decode/parser evidence, with explicit failed/not-attempted states; stable component/alignment and optional-response failure categories are nonexclusive target counts. Public aggregate counters do not contain raw exception reasons; `private_reason_counters` returns those separately for ignored private evidence only. Producer status text is not copied to manufacture agreement. Private mismatches, raw reason counters and warning text must not enter public artifacts.

## Explicit remaining orchestration and evidence limits

The library is deliberately not an ungated actual-data CLI. The parent must independently bind the pushed producer nine-file freeze, final review/test hashes, exact runtime/dependency/source pins, private input/parent/plan pins, unchanged completed bulk gate and census members BEFORE supplying any bodies or parsed rows. It must rederive actual96 selection and queries with this library, independently prove exact cache candidates from original completed manifests/ledgers/receipts, then decode one block at a time. `qualification_batch` does not infer these prerequisites merely because a caller labels an entry `exact_cache`.

After a completed handoff, retrieval statuses must originate from verified attempt ledgers, not producer outcomes. The library compares prefix facts; the parent orchestration must additionally compare original event current views, full target retrieval/status accounting, all aggregate panels and manifest output pins. Error-wording differences are explicit mismatches to investigate, not silently normalized away. Original accepted-pick parsing is already frozen upstream; independent reconstruction here consumes that accepted subset and does not claim to reconstruct unresolved annotations or a hypothetical complete earlier T0.

Recorded request clocks/body pins and the reviewed transport constrain requests. Stored artifacts alone cannot prove the absence of unlogged network packets, reconstruct dropped bytes not durably recorded, or recover a process's transient memory maximum. No attempt is made to repair that missing evidence or infer complete scientific support from an interrupted run. Native warning capture is single-threaded POSIX, confined to the auditor's process; it must not be embedded in a concurrent service.

The reviews exposed producer/contract evidence discrepancies. The frozen old core treats any finite flat prefix as a candidate, while the frozen prose requires flat/repeated-extreme runs>=8; this independent auditor follows the prose and retains short-prefix flatness separately. The producer's whole-XML public parser can reject an invalid wholly future epoch; this auditor defers timestamp errors until an epoch is relevant and prunes other epochs before public response parsing. Neither discrepancy authorizes edits to the producer or reinterpretation of a failed run. Producer Python warnings are per-response, but native stderr is globally retained in its worker log rather than each response JSON. Exact per-response native-warning equivalence is not recoverable from those JSON fields alone: missing-versus-captured evidence produces a private discrepancy, not an inferred match. Global native logs require a separate parent handoff and can remain unassignable to an individual response.

Public reporting remains aggregate counts/hashes only. Raw rows, IDs, station identities, XML/miniSEED, plans/receipts, native stderr and discrepancy details remain ignored. No response weighting or success-only denominator is allowed. These are retrospective annotation-conditioned native-count engineering checks; they establish no calibrated physics, operational picker/telemetry performance, sequence independence, trainability floor, model accuracy, novelty or superiority.

## Focused tests

Exact native sample-period numerator/denominator fields participate in component comparisons, including field presence. A producer omitting those fields has an explicit private evidence discrepancy; matching sample counts and floating rate booleans does not supply a missing rational clock. No missing field is filled from the independent result to manufacture agreement.

Loss of access to a pinned body between passes stops replay as unverifiable provenance, even for a non-resource PermissionError; it cannot become a target decode absence. Resource OSError remains ResourceStop. Explicit native or wrapped evalresp allocation diagnostics stop replay even when a generic wrapper exception or apparent transfer result is returned. Captured diagnostics remain private.

Explicit wrapped header/declaration/decoder allocation diagnostics also stop replay, including mixed fresh/cache blocks. Decoder floating-rate consistency allows at most two representable floating steps (ULPs) for equivalent factor/multiplier evaluation orderings; native exact fractions still define every crop and lattice period. This tolerance cannot admit a deadline sample or substitute a guessed rational rate. Both100/−3 and−3×100 native representations are tested end to end.

The cached-response panel joins the triplet already selected from current channel metadata. Extra ENZ channels in the response body cannot replace or reject a selected12Z triplet; each selected channel must still be unique, concurrent and exactly matched. Sensor-family precedence is used once on the current channel metadata, before waveform qualification.

`test_auditor.py` uses synthetic complete source frames, station arrivals, XML, arrays and failure fixtures. It tests strict edges/nonfinite future data, decimal sample rates, epoch transitions and missing starts, family precedence, rate/lattice/gap/overlap failures, fragment-invariant runs, shared new+9-cache declared/actual caps, no fallback, changed pins, source/current-view denominators, cache/query equivalence, request deadlines, incomplete-result rejection, selected-response isolation, OS resource interruption, separate response-failure counters and public native miniSEED/StationXML/evalresp primitives. No fixture is a real event or station record.

The native100/3-Hz fixture encodes201 invented FLOAT64 samples and explicitly patches the fixed-header factors to100 and−3. Sample200 lies exactly at6seconds and is NaN; only samples0..199 may qualify. The49-test snapshot excludes that boundary sample and preserves native30000000-ns periods for cropping/alignment. Tests also cover all factor/multiplier sign combinations, Blockette100 binary-rate precedence, malformed offset minutes and header ResourceStop. The public [ObsPy record API/source](https://github.com/obspy/obspy/blob/master/obspy/io/mseed/util.py) documents the header layout and SEED rate rules; the exact installed source is pinned separately. The indexed [FDSN SEED manual](https://www.fdsn.org/seed_manual/SEEDManual_V2.4.pdf) returned404 during this access, so no claim relies on its unread full text.
