# Post-collection legacy compatibility shadow v1

This new, exploratory, zero-network diagnostic uses the unchanged six-event cohort and eighteen already collected bodies: original QuakeML, fresh QuakeML and native SC3ML for each event. It preserves the previous diagnostic, all eighteen slots, input order, unknowns, original clocks and acquisition history. It neither selects replacements nor changes any census/counts protocol. No real body has been read during source development. Compatibility is a source-derived hypothesis, not proof of deployed conversion, physical picks, timing availability, EEW accuracy or improvement.

The public API is `projection.project(body, event_id, representation, profile=None)` and `shadow.run_shadow(events, provenance)`. Both accept in-memory bytes and have no file, network, process or write code. Parent owns a separate actual-read authorization after tests, first clean code-only review and pushed freeze. Before reading data, its bounded reader must verify exact source/runtime/authorization/input pins, independently recognize native root/version, preserve all original inputs, run a process-group watchdog covering import/validation/computation/output for at most 120 seconds, and write exclusively to a new private output destination. Declared hashes in these functions cannot prove that gate or historical clock provenance. Output must never overwrite existing files. No stylesheet is executed or imported; no schema engine or external dependency is installed.

Bodies are UTF-8/XML, at most 4 MiB each, exactly six unique events times three members, at most 96 MiB total. DOCTYPE, ENTITY, NUL, malformed XML, more than 100000 elements or depth over 64 are unsupported. Output serialization must be at most 8 MiB; overflow fails the entire invocation without partial promotion. These are frozen safety bounds, not scientific exclusions. The 96 MiB ceiling is conservative; eighteen 4 MiB bodies sum to at most 72 MiB. Parent retains a separate receipt on any error and eighteen input pins. The pure functions cannot enforce a wall deadline; that is explicitly parent owned.

Native profiles are exact root/version 0.10 or 0.11 namespaces. Mixed, foreign, missing, contradictory profiles, multiple containers/events, substituted event/preferred-origin IDs, ambiguous referenced origins and wrong-type publicID collisions remain unknown. A supplied native profile must match its root. QML 1.2 uses BED 1.2. Any modificationTime/passedQC extension requires an explicit 0.10/0.11 profile bound to an independently recognized paired native root/version. Plain-core QML may be read without a profile. The cohort conservatively withholds that binding when native projection is unknown; it may still read plain-core QML. This never proves which converter was deployed.

Source profiles come from the pinned GeoNet official commit in `upstream_source_pins.json`, with the exact namespace and transform locations in `upstream_PRIMARY_SOURCE_AUDIT.md`. The selective reader maps event-referenced origins; selects picks through referenced-origin arrivals and referenced stationMagnitude amplitude pickIDs; and records scope/multiplicity. An amplitude without its value child may select a pick without being emitted in converted QML. Raw identities, paths, flags and evaluation metadata are retained separately from candidate mappings. Raw ID mapping preserves smi:/quakeml: and otherwise prefixes smi:nz.org.geonet/ with ASCII space/colon translated to underscores. Empty/missing/NA placeholders, distinct-raw mapping collisions and dangling/duplicate pick targets never establish correspondence. Duplicate picks remain unresolved; ambiguous origins/amplitudes and cross-type IDs make the representation unknown.

Arrival weight uses literal source predicates: present weight is copied when timeUsed is exactly true/1 or all three flags are absent; missing weight with timeUsed true/1 yields 1; otherwise the projected timeWeight is absent. Raw flags are retained. Unrecognized boolean lexicals are unsupported; padded schema-valid booleans remain literal and do not become true through normalization. The preserved associated-P predicate accepts P/Pg/Pn/Pb, a unique pick, positive finite binary-float timeWeight when nonempty (underflow to zero rejected), status other than rejected, valid aware pick time, and nonempty station/network. Missing projected weight remains accepted as in the original predicate. NZ counts are a subset. No use flag proves operational availability.

Exact native reported status is suppressed in the candidate while raw status remains. modificationTime is accepted only in its exact native namespace under creationInfo, or the profile's native extension namespace under BED creationInfo. passedQC in 0.10 or BED passedQC is unsupported. The 0.10 stylesheet's generic fallback is documented separately and cannot establish schema membership. In 0.11, passedQC is only metadata at native origin/stationMagnitude or the exact 0.11 extension under BED event/stationMagnitude; true/false/1/0 after XML whitespace collapse, with raw lexical text retained. It does not affect P acceptance. Full schema validation remains false.

Comparisons retain exact event/preferred-origin identity, complete finite origin geometry/time, and the lexical arrival multiset as the primary content guard. A finite-binary-float canonical weight match is a separate diagnostic; it never promotes the guard. Depth is converted from km to m for the supported native origin. Exact candidate creationInfo fields and all present valid aware recorded timestamps are required for the matching-recorded-time label; any known lexical conflict blocks that label. Missing/invalid timestamps stay unknown. No label proves an atomic database revision.

Recovery counts are distinct left-qualified reference IDs: gained unique object IDs; newly accepted across networks; newly accepted NZ; content-matched candidates; and candidates additionally matching recorded revision evidence. An existing unique pick repaired with valid time/station fields can become accepted without a newly unique object. These are diagnostic counts, not converter defects or physical verification. OriginalT0 is a mandatory independently supplied integer microsecond UTC clock or explicit null. It is never derived from the shadow. Each representation retains its own clock plus strict station counts at originalT0+1/3/5 seconds (`<`, station deduplicated, no synthetic nonnegative delay restriction). Null clocks and unavailable representations stay null, not zero.

Only authored code, invented tests, this protocol/specification and the curated public documentation/pins enter code review. Raw stylesheets/headers and all actual IDs/XML/plans/receipts are excluded. Parent privately retains event-level results; only aggregate statuses, bounds and provenance may be promoted. First clean review ends source edits. Any later processing change requires another version, tests, review and freeze.
