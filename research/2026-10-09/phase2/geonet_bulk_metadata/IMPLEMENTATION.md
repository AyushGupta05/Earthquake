# Frozen metadata implementation

This helper implements the immutable scientific specification in `PROTOCOL_v1.md` (SHA256 977fa551f782341696f632ae2e19d0a9d6e144e2ee380c146fc60bf83b46932c) and `sample_specification.json` (SHA256 5719ece214bcb4f88a6da7c32f3421efd3d4e5f8bb516b8f9c3e6fe852ac0943). Preparation is local only. Collection remains disabled until the parent commits and pushes the exact reviewed sources and creates a private receipt bound to the prepared plan, inputs, library and runtime. No waveform, station response, model or cloud action exists here.

The original checksum-pinned census downloader and associated-P parser are loaded from their verified bytes. The new origin-only extractor uses its namespace, singleton and UTC/finite-number helpers. It independently verifies event identity and preferred-origin linkage so that a malformed P singleton can leave valid origin/time evidence while P coverage remains unknown. It does not change the reviewed P failure or origin-association rules. Geometry errors likewise do not erase valid P coverage. Depth is in meters relative to the QuakeML BED 1.2 WGS84 geoid nominal sea level; a finite negative depth is preserved. Optional origin type and referenceSystemID are offline diagnostics. Official depth reference: https://quake.ethz.ch/quakeml/docs/REC?action=AttachFile&do=get&target=QuakeML-BED-20130214b.pdf .

All 346 selected lower-M events and 149 reused tail events are written as denominator placeholders before acquisition. Reused raw files are checked against their original manifest/request hashes, parsed again with the unchanged library and compared exactly with the previous outcomes; no tail request is made. The raw CMT row references, methods, literal minute-start times and magnitude values remain private. Fixed hash selection probabilities and weights are retained for failures, never used to replace an event. Aggregate weighted positive-coverage bounds put unknown weights between zero and one; they do not assume failed queries are known absence. Unresolved P references, invalid/naive P times or missing station identity turn zero accepted NZ coverage into unknown. A positive accepted NZ subset remains known >=1 lower-bound evidence; incomplete structure is separately counted in positive and zero subsets. Deliberate rejected/nonpositive-weight exclusions alone remain known zero. Histograms describe accepted valid picks and their unchanged T0, not complete underlying P coverage. Positive subset counts are lower bounds only at this fixed accepted-subset clock; they are not necessarily lower bounds at a hypothetical earlier T0 from fully resolved picks. The original clocks/counts are preserved.

The total 1,800-second launch bound starts from initial module loading, includes preparation validation and imports, and is independently enforced by the parent process against the child process group. The child receives the same absolute monotonic parent deadline and stops acquisition ten seconds early to allow checkpoint finalization inside the outer window. A small transport adapter preserves every attempted request before opening its connection and durably appends each returned body chunk to a sidecar/atomic ledger, including monotonic start offsets. Soft SIGALRM/SIGTERM signals are masked before read1 through chunk persistence. The exact pinned CPython3.14 HTTPResponse/SocketIO socket receives a deadline proxy that reduces its timeout before every recv_into (including repeated chunk-header/CRLF reads), preserving the absolute 20s/outer deadline while the handoff is masked; unexpected stream shapes fail closed. The installed standard-library read1, SocketIO.readinto and urllib do_open implementations were inspected locally before this adapter change. It retains the unchanged reviewed Fetcher request/byte/deadline/redirect logic and native finished statuses; a pending alarm after a chunk returns cannot erase its byte accounting. The parent starts interruption finalization within that reserve, keeps a hard watchdog through cleanup, requests bounded graceful termination when possible, and kills the complete process group/exits at the absolute deadline rather than extending cleanup. Native request-ledger finalization uses an atomic persistence hook, and byte reconciliation uses the pre-request total plus returned-chunk count to avoid double counting pending signals. Private interrupted sidecars are reconciled into raw bodies without parsing or making new requests. Recovered manifests explicitly clear superseded artifact pins and mark artifact_pins_incomplete=true; no stale checksum is asserted. A hard-stop marker or incomplete pins forbids a completed scientific interpretation. Any per-request timeout ends the run incomplete. The child retains the reviewed whole-request 20-second alarm, one-second request-start spacing, no redirects/retries, 4MiB per-event and 128MiB combined body ceilings. The exact frozen list contains 346 attempts at most despite the 400 safety ceiling. Interrupted or capped runs retain every denominator and report incomplete, rather than a positive or negative scientific feasibility conclusion. Local inputs are bounded (32MiB per census JSON, 2MiB plan, 1MiB receipt, 4MiB individual raw XML); generated checkpoint reads use a separate 1GiB ceiling, and request bytes retain the stricter 128MiB acquisition cap.

The final runtime is the exact existing original-census Python 3.14.5 (`/opt/homebrew/opt/python@3.14/bin/python3.14`), resolved binary SHA256 2477b47fa3ae65b9574eb18a15edb364e96948eaa1875ad3f1c80d780efc9c12; only its standard library is used. The earlier Python 3.10.20 preparation is retained as a failed preflight: variable fractional widths changed 99/149 cached parser outcomes, despite invented fixtures then passing. No metadata requests occurred. A six-width invented UTC compatibility guard and exact original Python-build/binary checks now run in preparation; all 149 cached base outcomes must compare exactly before private plan output or run-directory reservation. No installation or global write is needed. Preparation pins the actual executable, resolved binary hash, version, cache tag and architecture, and collection must use that same runtime. `-B` prevents bytecode writes during tests/launch. The runtime receipt is generated locally during preparation, not assumed from this prose.

`prepare --plan local_runs/planned_inputs_final.json` writes one deterministic, private plan with exclusive creation. `collect --plan ... --receipt ... --output local_runs/collection_final` requires a private parent receipt with version `geonet-bulk-parent-receipt-v1`, acquisition_authorized=true, code_only_review_clean=true, the 40-hex pushed git_freeze_commit, plan_sha256, processing_files, library_sha256, input_pins and runtime. The receipt itself must be under local_runs. The parent owns promotion, receipt creation and execution. Existing destinations are never overwritten or resumed. Atomic temporary files include the process ID, avoiding parent/worker rename collisions. The parent finalizer kills/waits for any live child under the absolute hard watchdog even if recovery persistence itself raises; it disarms the timer only after the child has stopped. Parent SIGTERM enters this same bounded interruption path; further soft cancellation is ignored during cleanup, and original handlers are restored only after the worker has been confirmed dead. Forced SIGKILL is awaited under the still-active absolute watchdog before any worker-owned checkpoint is read or rewritten. Generated artifacts are hashed in bounded streaming chunks with the separate 1GiB artifact ceiling, rather than incorrectly applying the 128MiB network-body cap to expanded JSON.

Invented fixtures use synthetic event identities/XML and fake fetchers only. Real IDs, rows, query URLs, QuakeML, credentials and plan/receipt files stay in ignored local_runs and never enter the reviewer or Git. Independent post-run replay must verify all frozen members, request ordering/count/body accounting, raw hashes, the 346+149 denominators, original-tail equality, strict pick-clock station counts, origin singleton/geometry/time diagnostics and gate counts without importing these audit modules or making new requests.
