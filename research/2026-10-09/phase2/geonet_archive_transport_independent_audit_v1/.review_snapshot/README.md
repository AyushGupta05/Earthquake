# Independent four-slot archive transport replay auditor

Stage: source-only implementation against the authored first-clean public V2 contract. No collector implementation, actual plan/roster/IDs/keys/metadata/bodies/receipts, accounts, waveform acquisition, raw external sources, AWS, fits, installs, or shared Git are permitted during development/review. Previous frozen sources, tests, reviews and the final nine-file mapping documentation packet remain unchanged.

The pure interface is `audit(plan_bytes, manifest_bytes, bounded_member_reader, *, execution_summary_bytes, execution_summary_pin)`. The parent supplies a separately authorized bounded reader and immutable source/runtime/input/profile/authorization pins. The module has no file reader, HTTP client, CLI, subprocess, acquisition, model code or data publication authority. Exact API and outcome limits are in `PROTOCOL.md`.

The source-only replay scope is four immutable ordered literal-key slots; deduplication and allowed attempts; no replacement/retry/redirect/HEAD/authentication/requester-payer; exact delivered-body/error/partial bytes and hashes; per-member64MiB and aggregate256MiB ceilings; recorded monotonic deadline/spacing consistency; final completion and termination confirmation. Missing/incomplete final manifests cannot qualify any transport result. Failure and unavailable slots must remain present, and unattempted artifacts cannot be read or promoted.

The finalization bound also requires a parent-pinned returned execution summary. A request receipt serialized before final-manifest completion cannot establish the outer return deadline. The reviewed schema must define the summary's exact clock fields and custody linkage; missing or inconsistent evidence cannot qualify the full-run bound. Replay checks recorded arithmetic and consistency, without independently measuring real elapsed time.

Mapping status remains `unverified_hypothesis`. Transport evidence cannot establish GeoNet's UTC filename basis, blank-location convention, semantic NSLC/day identity, miniSEED coverage, causal availability, physical timing, EEW feasibility, model improvement, or complete archive mapping. Even eventual replay success will concern the exact preregistered literal address and recorded transport assertions under parent-owned acquisition authority.

Development tests will contain invented slots/keys/bytes only. Code-only Codex autoreview will use an isolated Git snapshot, curated public contracts and invented tests, without raw third-party texts or actual data. Advisory findings will be independently verified and actionable defects corrected; tests and the same review engine will repeat only until first clean, then source edits/reviews stop and a safe allowlist/hash manifest will be frozen. No actual replay is authorized by code review.
