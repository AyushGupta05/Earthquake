# Independent paired selection and artifact auditor

This is a separate stdlib implementation, prepared without actual input records, XML, plans, receipts or collections. It never imports producer modules or executes the official transforms. Only public protocol/specification/source schemas and the two inert official GeoNet transform texts were consulted. Source-only preparation and invented fixtures are authorized; actual replay remains disabled until a separate parent hash-bound handoff after source review/tests and a pushed freeze.

## Exact checks

Before ranking, all 149 reused-tail identities, CMT magnitude/date, row-index membership and derived calendar partitions are checked against the pinned original census rows, groups and query list. Thus a copied bulk eligibility error cannot silently change a control candidate pool. Native originReference elements must be scalar containers; child content is unsupported evidence.

The selection replay independently reconstructs the 495-event frame (149 reused-tail plus346 lower-M), original TEST Mw≥6 eligibility, all3 incomplete [6,7) plus1 incomplete ≥7 probes, and one complete control per band using the frozen SHA256 seeds. Unknown original candidate status blocks selection rather than becoming complete. It independently reconstructs six-event order, alternating12 eventid-only GET URLs/files, preserved original census T0, all row fields and counts. It checks seven original census hashes, six bulk input hashes, the independently completed bulk gate, original149 base equality, six successful original request/body/member pins and parent source/runtime/specification bindings. It verifies the shape of the original producer projection digest but does not claim to independently reconstruct that producer-specific digest.

Artifact replay requires the parent's completed, normally exited and preserved collection handoff. It checks all16 fixed member size/hash pins, including twelve delivered response files, and rejects extra/missing members. It binds the acquisition receipt, plan, sources, runtime, caps and manifest; checks12 exact attempt identities/order, per-response4MiB and total48MiB bodies, recorded20s request duration and360s outer duration, and recordedUTC start spacing≥1s. Recorded times are evidence from the producer ledger, not independent monotonic network instrumentation. Any recorded bound violation fails; no timing tolerance is added.

All six events retain all18 representation slots. Unknown slots must retain null denominators/picks/clocks. Parsed saved accepted subsets must satisfy unique IDs, count ordering, earliest station clocks and strict `<anchor+h` counts at1/3/5. Original accepted-subset T0 is preserved independently of later stricter XML support. The check verifies arithmetic over the saved subset, not whether the subset exhausts true associated P coverage. Incomplete zero subsets retain unknown coverage; positive subsets are lower bounds at their preserved subset clocks, not at an invented earlier clock.

The narrow independently parsed XML profile verifies exact supported root namespace/version, one event and matching identity, preferred-origin linkage, native originReference uniqueness and mapped-ID collision exclusions, singleton time/geometry and lexical creationInfo. Native depth is multiplied by1000 without Decimal rounding. A saved null geometry/time field remains unavailable even if the independent raw parser can represent it; it is not counted as numeric agreement. Verified and unavailable origin-field counts are separate. QML publicID attributes match literally; mapped native attributes remain literal. The profile conservatively declines native preferred references containing surrounding whitespace, because full text mapping and linkage cannot be asserted from this narrow check. DTD/entities, non-UTF8 encoding, duplicate/foreign evidence fields, unsupported roots and tree-size/depth excess yield unknown raw-core evidence. Unsupported does not become a negative coverage result. It does not diagnose unrelated XML semantics as a converter bug.

Where both saved representations are parsed and the independent raw-core profile supports both, recorded revision evidence is independently derived from all seven lexical fields of event/preferred origin. A known conflict must suppress both content-matched and matching-recorded-revision recovery promotion. Equal valid recorded times plus equal fields support only a recorded-time match. Native modificationTime under BED creationInfo is accepted only in one of the two exact supported SCML namespaces, uniquely across namespaces. No atomic database revision is verified. URI normalization, full arrival signatures, accepted-pick eligibility/use flags, stationMagnitude/amplitude pick scope and complete transformation/recovery counts are deliberately **not independently certified** by this auditor.

## Interpretation limits

`all_scoped_checks_pass` means the listed integrity/selection/clock/core-revision checks passed. It is not a blanket scientific-semantic pass. The report always sets complete arrival/conversion semantics, recovery counts, physical/operational timing and model-improvement verification to false. Raw-core unavailable slots remain in the18 denominator. Parent must not treat this narrow auditor as an independent confirmation of metadata recovery or a conversion defect. If those claims become necessary, freeze and review a separate deeper semantic auditor rather than silently expanding this one after seeing actual data.

## Runtime and bounded I/O

Reuse the already installed original-compatible Python3.14.5 environment; no installs or array/waveform imports. Stdlib only, each JSON≤32MiB, each response≤4MiB, cumulative cached input bytes≤256MiB; executable hash read≤128MiB separately. XML≤100000 elements and64 depth. All inputs are nonsymlink files under the workspace's work/ directory, with explicit parent-supplied paths and exact size/SHA pins. No data discovery or network code exists. Runtime version/cache tag/binary hash and exact auditor/source hashes are rechecked. Output is one new exclusive JSON under this auditor's ignored local_runs/; no overwrite, resume or source mutation.

The CLI arms a300-second soft alarm with remaining time measured from process import. Parent must additionally execute the whole invocation under a330-second process-group watchdog to cover startup, finalization and filesystem stalls; this is an auditor limit, separate from the producer's360-second acquisition. Resource/provenance errors yield a failed scoped check, never a scientific absence. The parent must preserve a normal-exit receipt and actual output hash. Review sees source/tests/protocol only, never private receipts/paths/IDs/XML.
