# Audit of the October 2026 conformal PGA paper and April archive

Audited 2026-10-09. **Useful uncertainty baseline, not evidence of lower magnitude point error. The archive predates and materially differs from the accepted paper.** This is a static source audit: no author scripts ran, no model checkpoint was deserialized, no training ran, and no project TEST data was opened.

The publisher identifies Youngjae Shin and Woodon Jeong, *Geophysical Journal International*, accepted manuscript, published 5 October 2026, DOI [10.1093/gji/ggag415](https://academic.oup.com/gji/advance-article/doi/10.1093/gji/ggag415/8865294). Its indexed primary abstract was available; opening the publisher article failed and I did **not** obtain or read the full manuscript/PDF. The abstract describes amplitude-retaining 3-second CNN–Transformer inputs, CQR coverage of 90.03%, heteroscedastic ensemble/dropout comparators, event-cluster bootstrap and repeated event resplits. It explicitly limits the theoretical guarantee to exchangeability and does not establish record exchangeability or event-conditional reliability. Detailed findings below apply to the archived implementation, not automatically to the accepted manuscript.

**Causality and amplitude audit.** `dataset.py:570–585` crops the 300-sample window before zero-phase filtering and normalization; `sosfiltfilt` therefore uses both directions **within the available 3-second crop**, not samples beyond its endpoint. It can be computed at the endpoint, although it is not a streaming causal filter. Normalization discards all component scales (`dataset.py:60–80`); the CNN/Transformer forwards accept only normalized waveforms (`models.py:118–123,240–249`). No retained amplitude features exist in this archived path.

The picker/preselection path is weaker: full-record mean subtraction precedes picking and SNR (`dataset.py:557–578`), and `_detect_p_arrival` also subtracts the full-record mean (`455–472`). Consequently later waveform values can influence the chosen onset and acceptance. The STA window looks 0.3 s ahead of the returned index, which is detection latency that must be counted. Subsequent crop demeaning cancels the constant full-record offset algebraically for a *fixed* crop, so this finding concerns picking/selection, not a claim that every normalized fixed-crop sample directly leaks future amplitude. A streaming recreation needs prefix-only baseline estimation and an end-to-end future-suffix invariance test. Also verify physical sample rates before assuming 300 samples = 3 s; the K-NET path uses configured sample count without visible resampling.

**Rare-event stratification uses unavailable catalog magnitude.** `generate_mondrian_cp.py:65–66,103–113,127–136` supplies true calibration/test magnitudes to `Stratified*Predictor.predict`; `conformal.py:368–377,474–479` selects an interval correction from that value. This is an oracle-conditioned diagnostic, not an early-warning magnitude estimate. Reporting coverage grouped afterward by true magnitude is legitimate; using that magnitude to choose an operational interval is a different information assumption. Archived M ≥ 6 CQR coverage rises from 86.16% (summary, global) to 90.23% (Mondrian JSON) with width 1.590 log10 PGA for 2,898 records, but does not demonstrate deployable tail improvement or 2,898 independent large earthquakes. Small strata fall back to the first calibrated stratum rather than the advertised global CQR (`conformal.py:337–375`); those fallback guarantees would need separate justification.

**Results and archive limits.** The April summary reports point MAE 0.2774 log10 PGA, SplitCP 89.98% coverage / 1.136 width, CQR 90.06% / 1.146, raw QR 89.08% / 1.122. These are source-reported, not reproduced, and cannot be compared numerically with our magnitude-unit MAE. The archive’s ensemble/dropout intervals use only variation among point predictions (`baselines.py:93–117,200–220`), omitting a learned conditional observation variance; their 19–22% coverage does not indict the accepted paper’s revised heteroscedastic baselines. The archived event-averaged CQR PICP is 90.75% versus record-weighted 90.06%; it is not the fraction of events whose every station is covered (`event_weighted_picp.py:36–57`).

Metrics include PICP, log-width, an exponential coverage-width penalty, point MAE/RMSE/R², magnitude/distance subgroups, alpha sweeps, latency, and threshold recall/precision/FPR (named FAR, computed FP/(FP+TN)). Upper-bound threshold screening at 25/80/250 Gal is a decision tradeoff, not probability calibration or magnitude-error reduction. The onset perturbation shifts an already normalized crop and zero-pads it (`onset_perturbation.py:38–49,95–127`); it does not re-extract actual adjacent samples or rerun the picker. Use that only as a synthetic crop stress test.

The internal manifest is stale/incomplete: README calls its checksums SHA256, but entries are 32-character MD5 values. Four main checkpoint MD5s, alpha-sweep and onset JSON match; **config, figure_data.npz and evaluation_results.json do not**. The latter contains only configuration (61 bytes), not the promised full results. See machine-readable hash comparisons; these discrepancies establish provenance limitations, not the cause. The downloaded ZIP itself is authentic to the Zenodo checksum. README labels code MIT and weights CC BY4.0, while record-level license is CC BY4.0; no standalone LICENSE file was present. Preserve attribution and clarify any source copying; an independently implemented control avoids relying on incomplete license text.

**Reusable controls for our 1/3/5-second project.**

1. Preserve prefix amplitude scales and compare a matched amplitude-removal ablation. Treat this as existing prior art, not our novelty.
2. Freeze each horizon’s predictor and compare raw distribution quantiles, SplitCP, CQR, and heteroscedastic/MDN predictive intervals. Report both interval score/width/coverage and unchanged mean/median/CVaR magnitude-error metrics. Conformal widening alone cannot meet the user’s lower point-error objective.
3. Reserve **a new, event-disjoint CP-calibration subset before training**, separate from checkpoint-selection validation. Our current TRAIN calibration used for NLL selection is not an untouched CP-calibration set. Calibrate operational strata from frozen prefix-available features (e.g. predicted tail mass/entropy); catalog-M strata remain evaluation/oracle controls. A true-M label-conditional construction would require explicit candidate-label set inversion, not passing the unknown test label to a predictor.
4. Report event-weighted and recording-weighted results with event-cluster bootstrap and actual rare-event counts. If simultaneous coverage across stations or 1/3/5 s is claimed, predeclare an event-level aggregate score and its exchangeability assumptions; three separate 90% marginal intervals do not imply 90% joint coverage.
5. Test real onset shifts, suffix invariance and changed network/region distributions. Keep the official TEST sealed and choose all correction rules on independent training-side data.

**Decision:** add this paper to uncertainty-calibration prior art and use a causally implemented CQR/MDN control. Do not use the April Mondrian gains as a claim to beat operationally, do not compare its PGA error directly with magnitude error, and do not describe the old archive as a verified implementation of the October accepted paper. Request/locate a matching accepted-version archive before a paper-level reproduction claim.
