# Independent auditor API

The exact frozen producer SCHEMA and ADDENDUM are copied public contracts. The root proposal is normative. `auditor.audit(plan_bytes, producer_bytes, bounded_reader, expected)` receives builtin bounded JSON bytes and an exact `{plan,producer}` object of `{bytes,sha256}` pins. Input projection and producer top-level field/claim syntax are checked before any reader or decoder call. Noncomplete producer output is rejected before payload replay. Parent preserves65/195 placeholders on invocation/input failure.

The bounded reader receives only original `%03d.body.private` names for17 fixed batch ordinals and limit=`expected_body_bytes+1`. Exact type, size and SHA are checked. Nonpositive batches never invoke it. Each positive body is read once, scanned by the allowed frozen public header scanner, and each validated nonzero record is freshly decoded separately by independent code using ObsPy1.5.1. No producer implementation is imported. The replay function's optional decoder hook exists for invented tests only; actual auditor uses its fixed native adapter.

The return is a PRIVATE dict exactly `{protocol,agreement,fresh_complete,audit_pass,reason,rows,cells,fresh_result}`. Fixed protocol=`geonet-POST-prefix-independent-audit-v2`, rows65/cells195. `fresh_result` has the frozen producer public contract shape and independently reconstructed decisions/hashes. `agreement` compares full canonical JSON (including strict scalar types); `audit_pass` requires agreement plus fresh complete process accounting. `reason` is supported/replay_disagreement/fresh_incomplete. Complete process accounting does not promote a training cohort or establish physical waveform truth. Private fresh output remains≤64MiB; wrappers must separately bound aggregate return serialization and all stdout/stderr.

All filesystem/source/original-selection/transport/runtime/cgroup/process/custody facts require parent proof before invocation. The API cannot establish them from pins or assertions. A rejected input raises ValueError before decoder use; its bytes contain no exception echo. Actual cgroup memory/runtime containment remains mandatory because in-process limits cannot bound a blocked/crashed native decoder.
