# Cached channel epoch metadata audit v1

Normative parent proposal: `PUBLIC_PROPOSAL.md`, SHA256 `0705ffa3edd1e31d4e4f802b52598a1f008646775b0771bc3a00e6333292769b`. This NEW pure standard-library diagnostic reads only the four byte strings that the parent explicitly supplies. It neither fetches nor enumerates files, reparses transport receipts, repairs the failed96 collection, decodes waveforms, changes archive keys, rotates axes, trains models nor manages AWS. Individual positive custody of a cached document does not complete its original failed whole run.

`audit(documents, slots)` has no I/O. Invalid Python API/schema inputs raise `ValueError` before any XML parse. A missing, over-cap, unverifiable, malformed, unsupported or out-of-scope XML input retains its fixed row as unknown. Exactly four rows occur in ordinary/higher/boundary/final order. Their actual identifiers, clocks, XML-derived fields, body pins and detailed reasons are PRIVATE. Only `public_counts` is publishable after parent verification; it has fixed denominator four, generic integer counters and explicit false claims. No returned raw XML is needed.

Document byte length is limited to 128 KiB each and 512 KiB total. Total excess makes all four rows unknown before parsing. UTF8 (optional BOM) and recognized FDSN StationXML namespace `http://www.fdsn.org/xml/station/1`, schemaVersion 1.0/1.1/1.2 are required. Active DTD/entity declarations and non-declaration processing instructions are rejected. Comment/CDATA text is masked only for lexical checks and remains unchanged for parsing, so inert examples of markup are not interpreted as declarations. A UTF8 XML declaration may begin the document; other encoding declarations are unsupported. ElementTree parses the bounded string, then traverses it with maximum 4,096 retained XML element nodes and depth 32 (root depth one). Comments are not retained element nodes; their bytes still count. Caps bound the accepted input/output scope, not a hard process RSS or allocation-time ceiling.

Validation is deliberately narrow: recognized root/version/namespace, Network directly under root, Station under Network, Channel under Station, required literal code attributes and Channel locationCode. Foreign namespace elements or misplaced hierarchy elements make the document unknown. Orientation, rate, sensitivity and units get their own field validity checks. This is **not full XSD validation**; all output flags explicitly keep that claim false. Other optional FDSN elements are not interpreted as proof.

Only exact parent-fixed network/station/location/two-character prefix matches are enumerated. Codes must be precisely that prefix plus one uppercase ASCII letter or digit. No trimming, empty-location substitution, wildcard expansion, alias, replacement, counterpart inference or 1/2-to-E/N mapping occurs. Additional literal suffixes including Z are counted as `other`; that bucket is not a classification of measured physical orientation. At least one matching Channel is needed for a valid document scope. A valid scope cannot establish inventory completeness. Missing cache content or absent suffix counters cannot establish physical absence.

For each present literal channel, all retained matching epochs and their original network/station parents are kept. Channel, station and network startDate are required. Explicitly absent endDate is open-ended **metadata only**. Date strings need an explicit `Z` or numeric UTC offset and at most nine fractional digits. Conversion uses exact integers/calendar arithmetic, never floating timestamps; leap seconds, zone-free dates, invalid calendar dates, offsets beyond 14 hours, unsupported precision and dates outside signed64 UTC ns are unknown. Raw date strings and parsed nanoseconds are private. Declared nonpositive epochs are unknown.

Window `[t0-3s, t0+h)` is unchanged at h=1,3,5. Support uses the conservative preregistered **strict interior** rule: start < left, absent end or end > right, for channel AND its own station AND its own network. Equality of either declared bound to either window edge is `boundary_unknown`; metadata does not settle inclusive/exclusive interpretation. A valid declared epoch that does not enclose the window is `not_supported`, which is a metadata result only. Any missing/invalid epoch within the retained group, or duplicate/overlap anywhere in the matching channel/network/station groups, is `unknown`; none is discarded in favor of a latest row. Adjacent disjoint epochs are retained; a uniquely enclosing epoch may support a window. Ancestor failure prevents support. When all required valid pieces are considered, a known non-enclosure takes precedence over a boundary ambiguity in another piece. Support cannot establish sample continuity or usable E/N/Z pairing.

Numeric fields use Decimal strings without rounding. Azimuth is finite within [0,360], dip within [-90,90], nominal SampleRate finite and strictly positive. Missing/duplicate/nested/nonfinite/unparseable fields remain present/invalid as appropriate; they do not retroactively rewrite epoch metadata. Raw and exact decimal values are private descriptions, not measured axes or agreement with waveform sample rates. Response element count, direct Stage count, InstrumentSensitivity presence/count and finite Value/input/output unit names are descriptive only. Empty or conflicting response fragments never prove full response or physical calibration. No stage validity, complete transfer function or geometry tolerance is inferred.

Public suffix presence counts have denominator four DOCUMENTS and count a kind at most once per row. `literal_channel_count` counts distinct codes per valid row; `epoch_record_count` counts all retained matching Channel elements. Horizon state counts use that variable literal-channel denominator, and unknown-document counts remain separate; there is no invented absent-channel row or event-level three-component pass. Orientation/rate/response counters use retained epoch records. These denominators prevent a missing cache document from becoming an absent channel.

The parent must verify exact source/test/review/manifest closure, publish source, then prepare independent private per-document positive HTTP200 custody and raw-byte pins from the old fixed requests. No actual cache body, inventory, identifiers, clocks, plan, receipts or results enter this source packet or the code-only reviewer. An actual invocation is a separate read-only parent diagnostic. All claims of physical absence, holdings, measured axes, full response, calibrated waveform, complete failed run, continuity, online timing, model gain or novelty remain false.
