- `noise_support(powers3x12) -> (noise12x3,weights12)`: builtin finite nonnegative powers<=1e24, fixed natural-log delete-one-quarter medians with floor1, column centering, same index across3components, weights1/12. This is an empirical sensitivity prior, NOT a true-noise posterior or twelve independent degrees of freedom. Original pre-T0 centering/quarter powers are supplied by a separately qualified source. Zero spread remains zero without asserting certain noise.
- `start(pi5,mu5,sigma5,noise12x3,noise_weights12,arrival_offset_ns=0) -> immutable State`: fixed original proper Gaussian mixture and joint finite nuisance prior, BEFORE any waveform/mark likelihood. Numeric model inputs finite builtin abs<=1e6, sigma>=.05; weights nonnegative/sum1±1e-12, normalized only by their supplied sum. This is input representation validation, never magnitude-support truncation. General numerical controls can supply alternative noise weights/support; an actual sensitivity-method binding requires the fixed centered12/uniform construction above. The source cannot prove a supplied prior excluded first-waveform data; parent source/custody must. Arrival offset is immutable exactbuiltin integer P−T0 in[0,750000000]ns, making firstcell available at1s. No clocks/dates/eventIDs as neural fields.
- `append(state,new_cells) -> NEW State`: nonempty suffix only, at most20 total cells; each exact dict {cell,a,b,sigma,value}; cell numbers exactly currentlength+1 onward, all vectors length3. Positive reported logratio values must be finite and >delta=-12; None is the declared left-censor symbol, not a measured point or missing row. a/b/sigma encode already-causal affine means a+b*m from the fixed TRAIN model/history. No prior/noise override arguments. All caller arrays/lists are copied to immutable tuples. Directly constructed State objects must recursively contain tuples for all prior/support/cell vectors; mutable nested objects are rejected both before append and inference. The same joint noise support/index/weights and arrival offset survive every append. Do not build a new start object at a later deadline; root binds that identity separately.
- `Posterior(state,target,processing_begin=parent_beforecall,budget_seconds=10)`: independently completes positive Gaussian factors using precision-weighted means, with an explicit conditional-scale roundoff veto (bound<=1e-10 conditional sd); it for every active noise/prior pair. Censors multiply normalCDF factors and use mode-scaled all-real adaptive integration; a finite-difference derivative curvature is ONLY a change-of-variable scale, not a density approximation. GH64/GH128/adaptive global mean/lognormalizer/targetNLL errors<=1e-4 required. Deadline/cap/normalization/representation/quadrature failures raise NumericalFailure. No automatic surrogate/fallback/accepted repair. Evidence offsets, component peaks/lognormalizers and accepted target NLL logdensity terms must have float64 ULP<=1e-10; larger offsets are explicitly rejected as evidence_precision with scalar diagnostics. This conservative representation veto prevents common-offset cancellation that GH/adaptive parity alone cannot detect; it neither clips observations nor alters the likelihood or magnitude support.
- `.summary()` returns acceptedTrue,cells,components,integrals{adaptive,gh64,gh128}{log_normalizer,mean,nll},errors{log_normalizer,mean,nll},noise_probabilities12,pit(target CDF),work,censored_CRPS_verified=False. No CRPS, quantiles or median are implemented or claimed for ANY mode; this is a limited normalizer/mean/NLL/CDF prototype. Actual all-metric scientific comparison remains unearned.
- `.cdf(m)` includes exact±infinity endpoints and otherwise finite real m; `.density(m)` accepts finite real m. Posterior magnitude support is all real. CDF uses a ratio of weighted componentCDF sum to the same floating weight sum, not clipping, and rejects out-of-range probabilities. Density evaluation can fail for unrepresentable extreme arithmetic; that does not truncate model support. Target/density/CDF query is not restricted by the model-parameter abs1e6 input bound.

Rejection retains the original immutable State/target and available diagnostic errors/integrals/work, completed/current component fields even when construction stops midway, not a new Gaussian or fitted replacement. State is an in-memory dataclass, not JSON/pickle IO authority; parent may serialize a validated numeric state via its own bounded explicit representation. Invalid input objects are not safe export recipes.
