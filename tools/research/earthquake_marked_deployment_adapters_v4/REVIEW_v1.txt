source_binding.py:201
Replacing sys.meta_path with only Guard removes PathFinder from importlib.invalidate_caches() dispatch, and Guard has no invalidate_caches method. The supplied PyTorch instantiator explicitly calls importlib.invalidate_caches() after writing its generated helper. If a prior lookup has cached that temporary directory before the helper is created, a same-directory-timestamp creation can remain invisible and the subsequent helper import raises ModuleNotFoundError despite valid pinned bytes. This regresses the existing generated-helper extension. Add a Guard.invalidate_caches method that delegates to the approved PathFinder while retaining the owned-chain checks.
