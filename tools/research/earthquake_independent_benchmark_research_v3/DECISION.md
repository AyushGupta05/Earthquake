# Independent 1/3/5-second validation: source-only decision

13 October 2026. **Recommend one next step: a ROOT-controlled, closed GeoNet lineage-and-support audit, before any additional provider query or model value is opened.** GeoNet has the strongest documented combination of directly estimated CMT Mw, observed local-network P annotations and provider originals. Its existing counts are only ceilings. No source inspected here is already qualified for ≥200 usable events, ≥30 Mw≥5.5 and ≥15 Mw≥6 at all three deadlines. These are planning floors, not a power calculation.

This packet contains public documentation research and a proposed preparation scope only. It uses no private rosters, metadata tables, waveforms, predictions, current candidate outcomes, checkpoints or credentials. There were ten search queries and ten explicit page opens, including failed opens, plus three finds. Some search results and documentation contain incidental public event examples; they were not selected, followed or used to define a cohort. No provider catalogue query, data download, Git operation, cloud action, fit or code change was performed.

## Why GeoNet is the executable first gate

The official moment-tensor README distinguishes Mw from ML, records inversion methods, flags external W-phase solutions and unknown-ID placeholder 9999999, and states that CMT solutions are not integrated with catalogue QuakeML. Preserve that source-specific target and explicit identity join; preferred summary M or Mw(mB) is not a substitute for directly estimated CMT Mw. Its minute-resolution date field is not the P clock. [Official CMT schema](https://github.com/GeoNet/data/tree/main/moment-tensor)

GeoNet documents archived miniSEED without server trimming, padding or reprocessing; station information includes epochs, orientation, sensitivity and an optional full response level. This supplies a route to originals, not proof of complete usable samples. Its archived data are retrospective; online packet arrival/detection latency is a different task. [FDSN documentation](https://www.geonet.org.nz/data/access/FDSN) Public IDs link to detailed earthquake QuakeML; the summary search does not supply all arrivals or alternate magnitudes. [Catalogue documentation](https://beta.geonet.org.nz/data/types/eq_catalogue) GeoNet provides free access, attribution guidance and separate catalogue/CMT/station citation DOIs; its website identifies CC BY 3.0 NZ. [Data policy](https://www.geonet.org.nz/policy)

**An event absent from the latest fit is not necessarily untouched.** ROOT must audit positive identity membership, roles, acquisition and model-selection exposure, including event/alias/sequence bridges to encoder fitting, normalization, calibration, loss selection, feature design using outcomes and manual outcome inspection. All stages and external pretrained models count. Public CMT label knowledge or metadata availability alone is not prior evaluation; do not automatically equate a catalogue census with model contamination. Keep acquisition-only versus outcome-use statuses distinct, and apply a declared quarantine rule. Station reuse is a separate disclosed domain issue; deleting the station code does not erase site/gain fingerprints.

**A calendar relabeling cannot repair an encoder trained on later events.** A strict 2003–2014 TRAIN / 2015–2017 DEV / 2018–2024 TEST study requires all fitted representations and calibration to obey those periods, or explicit compliant pretraining provenance. A current model exposed to later events can support only a differently scoped event-held retrospective diagnostic. A calendar-compliant retraining would require its own later authorization and protocol, after support is established.

## Frozen proposal for the next scope — not execution authorization

1. **ROOT-only local audit; zero requests, zero waveform reads, zero forecasts.** Hard cap 30 minutes / two CPU threads. Reuse checksum-pinned frame, aliases, previous metadata receipts and existing exposure manifests. Use original TEST31 role/identity membership only to keep it sealed and outside this new pool; never open its labels, waveforms or predictions, and never move its members to TRAIN/DEV. Apply that exclusion before exposing any new-row values. The research agent receives only aggregates and manifest hashes. Unknown lineage remains excluded/unknown, never assumed clean.
2. Retain the existing candidate dates and both documented sequence screens; do not tune dates, distance/time radii or region to obtain enough tail events. Quarantine any component intersecting prior exposure or spanning a calendar boundary. Report CMT-versus-preferred-origin uncertainty separately. If independently documented sequence labels are proposed to replace a percolating heuristic, freeze that distinct design and rationale before model outcomes; do not silently discard the adverse sensitivity.
3. Publish successive unique-event ceilings: source frame → calendar → sequence/guard → prior-use/alias quarantine → known pick qualification, with unknowns and reasons. Preserve exact CMT method/external-source strata. Advancing a declared candidate design requires **≥200/30/15 remaining candidates**; otherwise stop it before more waveform work. The documented sensitivity already fails the total floor; a pass under the primary screen alone is conditional feasibility, not robust sequence-independence certification. Final validation requires a separately defended, frozen sequence policy. With a raw ceiling of 19 Mw≥6, losing five already defeats the ≥15 gate. This arithmetic is not a predicted attrition rate.
4. **Only if ROOT's ceiling gate passes**, freeze a metadata-only tranche before any new associated-pick, receiver, mount or request outcome values. From the positive-eligibility 2018–2024 frame, include all remaining CMT Mw≥5.5 events; fill to at most 500 total events with lower-Mw events ranked by SHA256 of UTF-8 `geonet-independent-v3|EVENT_ID`, tie by ID. Order all selected IDs by SHA256 of `geonet-independent-query-v3|EVENT_ID`, tie by ID. No choice may use known or new pick/waveform success. Keep the full eligible-frame and selected-stratum denominators; describe this as a stratified feasibility screen, with lower-band inclusion fraction and frame weights reported. Weights do not correct waveform nonresponse. ROOT records immutable selection/request hashes before examining new values. Reuse verified cached QuakeML for selected members without replacement; request only selected uncached members. Proposed limits: 500 requests maximum, 30 minutes, 128 MiB bodies, 4 MiB per body, 20 seconds/request, serial execution, ≥1 second between starts, no retries or substitutions. A cap or unresolved group bridge yields incomplete qualification, never a clean cohort. No StationXML or waves in this tranche. Metadata-stage success earns only a separately frozen waveform audit, not a test result.
5. Preserve associated observed P/Pg/Pn/Pb annotation provenance and strict UTC boundaries. Define T0 as the earliest accepted associated NZ P in the frozen network policy; each deadline is **T0+t**, not each station's own P+t. A station picked later earns no additional window. Unresolved earlier picks make T0 conditional/unknown; theoretical travel times, CMT time and catalogue origin cannot fill them. Catalogue location/depth are audit fields, never model inputs. This is explicitly an annotation-conditioned regional-network benchmark.
6. A subsequent, separately reviewed waveform stage must establish ≥200/30/15 **usable events at every horizon**, retaining failure denominators. It should use original sample grids, prefix-only processing, causal station selection and a declared common population. No whole-record quality score or suffix may choose a convenient early subset. Counts-based engineering evaluation can retain missing response flags; calibrated physical-amplitude claims additionally require effective response, units/orientation and causal conversion. Metadata picks alone cannot pass this gate.

The target population is the pinned **CMT-selected** regional frame, not the natural rate of every NZ earthquake. Include its untouched ordinary-magnitude events without tail-only convenience selection. Later uncertainty must use event/sequence blocks; many station records do not enlarge the independent tail sample. All model selection ends before the new evaluation values are released by ROOT.

## What makes ESM a fallback, not a ready answer

The public ESM waveform interface offers CV acceleration in cm/s² and optional QuakeML/StationXML, but defaults to manually processed MP. CV's full causal processing chain and actual pre-P coverage still need verification. [Event-data service](https://esm-db.eu/esmws/eventdata/1/query-options.html) The advertised P-S service returns **model-based theoretical** times. [P-S documentation](https://esm-db.eu/esmws/p-s-arrivals/1/query-options.html) ISC documents associated observed arrivals and magnitude-author/type filtering, providing a potential separate linkage route; station-code/epoch ambiguity and local-network coverage still require an actual audit. [ISC arrivals documentation](https://www.isc.ac.uk/iscbulletin/search/webservices/arrivals/)

If GeoNet fails its untouched-support gate, the next external scope should be **ESM event-index plus directly estimated-Mw provenance qualification only**, not waveform acquisition. The official index exposes cross-catalogue aliases but its `mag_value` is a hierarchy of mixed scales; use per-event magnitude information, not that field as Mw. [Index schema](https://esm-db.eu/esmws/ogc/1/query-options_event.html), [magnitude service](https://esm-db.eu/esmws/event/1/query-options.html) Freeze the region/calendar, source-label precedence, lineage quarantine, request list and caps in a separate proposal before queries. Current docs do not justify promising enough tail events, complete raw clocks or an executable release checksum. ESM database CC BY 4.0 does not override individual waveform-provider licences; ESM25's author README specifies CC BY-SA 4.0 for its dataset. [ESM terms](https://esm-db.eu/), [ESM25 licence](https://github.com/SpinaCianetti/ESM25)

No new accuracy, novelty, superiority, operational EEW or foundational-paper conclusion follows from this feasibility note.
