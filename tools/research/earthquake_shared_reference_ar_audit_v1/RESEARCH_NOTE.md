# Shared pre-P reference uncertainty in autoregressive EEW factors

Prospective source-only analysis, 13 October 2026. No actual marks, checkpoints, metrics or held outcomes were read; no current packet/model was edited. The ongoing S/P/D study stays frozen. Recommendation: if a further study is earned, first compare **the same S support with its AR-consistent level-error loading**, changing neither support nor capacity. Treat this as a measurement-model correction/ablation, not a new statistical principle or a guaranteed tail improvement. A paired bootstrap is a separate uncertainty-support question.

## 1. What the frozen source actually specifies

The public native builder forms each component's 12 chronological quarter-second powers using one mean from the 3 seconds before T0. It takes `Nhat=max(1, median(12 powers))`, uses `y_j=ln(P_j/Nhat)`, and constructs `nu_ell=ln(max(1, median(delete quarter ell)))-mean_ell(...)`. The same omitted quarter index is used across all three components. The all-positive fitting variant uses one joint support index across all cells/components, with uniform weight1/12. It uses observed previous `y`, not a latent previous value. Source hashes are recorded separately.

Writing the already fitted form as alpha_j + beta_j(M−mref) + rho*y_previous, current S adds the SAME nu to every Gaussian conditional mean. This is a normalized, coherent empirical AR model with a **shared innovation intercept**. It is not automatically the observation model for a shared error in a denominator. These interpretations coincide when rho=0; neither source coherence nor a conditional-NLL win identifies the physical interpretation.

## 2. Exact proposed comparator

For one component, suppose a latent normalized level obeys

    z_1 = alpha_1 + beta_1(M−mref) + epsilon_1
    z_j = alpha_j + beta_j(M−mref) + rho*z_(j−1) + epsilon_j, j>=2
    y_j = z_j + u,

with fixed shared u and conditionally independent Gaussian epsilon_j. Here `u=ln(Ntrue)−ln(Nhat)` if z and y use the same numerator power and differ only in the reference denominator. Substitution gives

    y_1 | M,u ~ Normal(alpha_1 + beta_1(M−mref) + u, sigma²)
    y_j | y_(j−1),M,u ~ Normal(alpha_j + beta_j(M−mref)
                             + rho*y_(j−1) + (1−rho)*u, sigma²).

Thus the exact loading is d_1=1, d_j=1−rho thereafter. Equivalently subtract u from **both** the current value and its lag before applying the latent AR law. The first cell must not use `(1−rho)u`: its fixed zero initial history is not another noisy observed level. For the current three-component diagonal AR, apply this per component; a vector AR would use I−A, but introducing one is unnecessary here.

For a proposed fixed discrete joint support u_ell, use

    posterior(M) proportional prior(M|static_context)
       * sum_ell w_ell product_(j,c)
         Normal(y_jc ; alpha_jc + beta_jc(M−mref)
                       + rho_c*y_(j−1,c) + d_jc*u_ell,c, sigma_c²),

with previous history zero in the first cell. Sum over the shared index **outside** the full product. Gaussian completion still gives at most5×12=60 posterior components for the existing support and five-component prior, with the same parameter count. The dependence of d on rho must remain differentiable: the later-cell intercept derivative with respect to rho is `y_previous−u`, not just `y_previous`. The prospective reference scorer must export/check the loading explicitly; the old frozen core assumes loading1 and cannot silently certify the changed law.

The factorization also assumes a chosen conditional nuisance law q(u|pre-event data) compatible with the static prior. Because the static context includes estimated noise levels, treating p(M,u|context) as p(M|context)q(u|pre-event data) is an additional modeling assumption; a frequentist bootstrap law is not automatically a Bayesian posterior for u.

Sequential inference must retain the joint M/support state, or recompute from the unchanged initial prior with each cell once. A marginal M posterior alone is insufficient for a later suffix sharing u. Do not multiply separately normalized1/3/5 cumulative posteriors. Prefix clocks/available-cell rules are unchanged.

**Sanity identities to require before any data fitting:** loading equivalence to direct latent substitution; u=0 equals plug-in P; rho=0 equals current S at the same parameters/support; fixed-parameter first-cell equality; rho=1 removes reference error from later differences; mixed signs/negative rho remain finite; joint versus prefix/suffix equality; gradients include d(rho); unknown/future cells do not change earlier predictions. Under a coordinate shift `y'=y+k, u'=u+k`, the corrected likelihood is unchanged for fixed latent/context parameters. This is not full-method gain/reference invariance because the static prior also receives noise-level descriptors. At1s some clocks expose only one cell: with fixed coefficients those cases cannot benefit from the loading change alone. Refitted priors can differ, so do not claim after-training first-cell identity.

In innovation coordinates r_j=y_j−alpha_j−beta_j(M−mref)−rho*y_previous, a continuous shared Gaussian u produces covariance `diag(sigma²)+D Cov(u) Dᵀ`, where block D_1=I and D_j=diag(1−rho_c). Current S uses repeated I instead. This is a standard random-effect/errors-in-variables consequence, not a new covariance theorem. Near rho=1, blindly repeating u in every innovation can substantially misstate covariance, but learning rho/sigma can partly compensate; no sign of magnitude bias or score improvement follows from algebra alone.

## 3. The existing support is not calibrated reference uncertainty

There is an exact finite-sample limitation independent of any actual data. For12 sorted powers q_(1)<=...<=q_(12), each leave-one median of11 equals q_(7) when one of the lower six is deleted, and q_(6) when one of the upper six is deleted. Flooring and logarithms preserve these two possibilities. After centering, each component's nu is just ±half the log gap, six times each (possibly zero). Therefore12 paired points occupy **at most8** joint sign combinations. Each marginal is symmetric; the joint support need not be centrally symmetric. Independent component quantiles or changing the sign can therefore change cross-component dependence.

For even n, the full median is `(q_(6)+q_(7))/2`, while the average leave-one log is `(ln floor(q_(6))+ln floor(q_(7)))/2`. Centering also removes that difference from ln(Nhat). These are delete-one sensitivity points, not bootstrap draws, jackknife pseudovalues, or an established posterior for u. A calibrated noise-width or frequentist coverage claim would require separate evidence. Even multiplying a delete-one variance by a conventional jackknife factor would not turn12 dependent replicates into a posterior. Median/non-smooth statistic and short dependent pre-event windows make asymptotic shortcuts particularly weak.

A separate prospective paired-bootstrap diagnostic could resample the **same chronological quarter triplet indices across components**, recompute the three medians/floors, and preserve each resulting vector intact. For bootstrap estimator error e*=eta_hat*−eta_hat, a basic error-law approximation for u=eta−eta_hat is **u*=−e***. A percentile-style approximation to a parameter distribution is a different convention; it must not silently replace this sign, particularly for asymmetric joint support. Marginal quantiles may be reported diagnostically but must not be independently zipped into a joint nuisance distribution. If reducing many paired replicates, retain selected whole vectors and their weights under a rule fixed before values; no componentwise sorting/cross-product invented correlation.

Adjacent quarter powers and all three axes share temporal structure and the fitted pre-event center. IID resampling assumes away temporal dependence. Paired moving/circular blocks preserve some of it, but3seconds/12quarters are too short to establish stationarity or estimate an optimal block length reliably. Fix the block/replicate design prospectively and test it on invented stationary/colored/nonstationary noise with a known reference; do not choose it from magnitude outcomes. Holding the pre-event center fixed estimates only reference-median uncertainty conditional on that center. Re-estimating center uncertainty requires original pre-event samples or sufficient statistics; quarter powers alone cannot reconstruct it. The floor creates an atom and changes gain equivariance. A reflected basic bootstrap can even violate the floored parameter support at the boundary: if eta_hat=0 and eta_true>=0, true u>=0 but eta_hat−eta_hat*<=0. This is an explicit failure mode to diagnose, not permission to silently clip or declare that approximation calibrated. Report floor cases separately, without changing the original common population. More support points increase posterior/scorer cost beyond the currently fixed60-component contract and need a separate reviewed budget—not an implicit cap extension.

## 5. Smallest decisive future comparison and stop rules

First retain the current empirical nu support and all parameters, static prior, initialization/order, training objective/steps and population. Compare current shared-innovation S against **shared-level-error S with d=(1,1−rho,...)**, with P retained as the zero-support control. Do not change rho constraints, resampling, censoring or add rupture states in this comparison. Same real parameter/gradient/capacity accounting and proper-score closure are necessary; this note grants no new fit or runtime authority.

Only after the algebraic nulls pass should a separately frozen paired-noise support study compare the two loading models on identical support. This separates AR semantics from a new uncertainty width. Success must include natural-population proper scores/coverage plus the original fixed mean/median/bulk/tail/worst-error guards at each1/3/5deadline, each seed and ensemble. Current tiny reused DEV can support a pilot decision only, not foundational confirmation or a new independent test. Never choose bootstrap sign/block length/support size/rho policy from DEV.

Keep predictive and mechanistic decisions separate. Stop this development path or reject a predictive-improvement claim if gains require arbitrary uncertainty scaling, occur only after changing support rather than loading, or regress bulk/worst-error criteria. Those outcomes do not falsify shared denominator error: rho=0 makes the loading arms identical even when that error exists, and misspecified support or other nuisance terms can hide any benefit. Algebraic substitution/coordinate failures reject an implementation of the stated model. Controlled coverage failures under a fully specified synthetic law reject that implementation or its chosen uncertainty approximation. A physical observation-model test would need identifiable reference error and separately controlled center/waveform/process errors; predictive DEV scores alone cannot supply that test. A negative current S result would not prove the level-error comparator fails, but neither would it justify a broad sweep. A positive S result would still not calibrate its jackknife support or establish its physical interpretation. Unknown rupture duration, path/site effects, additive waveform noise and pre-event center error remain separate mechanisms; this correction addresses none of those by itself.
