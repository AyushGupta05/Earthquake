# Source-only public packet allowlist

Only safe_to_promote_paths.json members may be copied or published. They are authored V6 source, wholly invented test code/logs/reproduction, curated public normative proposal/template/uncertainty context, source-only review reports/snapshots and aggregate source/test/review/handoff custody metadata. Review1 failed source/contracts are retained historical evidence; review2 is the final clean processing snapshot. No private/actual input or provider acquisition occurred while preparing this packet.

Excluded: all .git metadata, bytecode, local_runs, actual metadata rows/IDs/clocks/literal keys/XML/inventories/waveforms/body or collection receipts/results, credentials/account configuration and raw third-party material. Paths are relative safe regular files; parent independently verifies bytes and read-only modes. This allowlist never grants actual execution authority.
