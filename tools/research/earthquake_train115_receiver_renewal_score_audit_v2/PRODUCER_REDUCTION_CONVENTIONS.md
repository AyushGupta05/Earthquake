This document specifies existing semantics for independent replay. It adds no processing operations. Original native hashes are verified on original dtype bytes before scalar conversion. Components are literal E,N,Z or 1,2,Z in that order; record pieces remain separate, chronological, and samples increase within each piece. Rational-period sample membership is exact half-open [lo,hi): indices ceil((lo-start)/period) through ceil((hi-start)/period)-1, clamped to the piece. Continuous support is required, with no gap fill, overlap repair, interpolation or resampling. Native i4 values become builtin int; f4/f8 become builtin float. Visited values become finite builtin float for reductions.

For each component, pre-T0 center is the arithmetic mean over [T0-3 seconds,T0). Iterate piece/sample order above, accumulate with math.fsum, then divide by exact visited sample count. For each of twelve chronological quarter-second windows, subtract this same component center from each scalar before multiplication, form residual * residual as a builtin float, accumulate using math.fsum, then divide by that window's sample count. Noise raw power is statistics.median of these twelve quarter powers (sort, average the central two). Effective noise power=max(1.0,raw); floor flag is raw < 1.0, so exactly one is not floored. Component order is unchanged.

Each observed post-P quarter-cell power uses the same scalar subtraction/multiplication/fsum/count ordering. Ratio is the maximum of the three component centered powers divided by corresponding effective noise power. State is strict ratio > 9; a ratio equal to 9 is quiet. Cells are nonoverlapping .25-second intervals. State reset ages and current deadline right censoring never fabricate a final exit. First cell uses [P,P+.25 seconds); current cells stop at T0+h. Pre-T0 noise and first cell are immutable across horizons.
