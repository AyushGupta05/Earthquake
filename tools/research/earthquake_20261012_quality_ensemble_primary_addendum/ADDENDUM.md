**GNSS quality filtering.** USGS's primary record for Dybing etal., *Detecting earthquakes in noisy real-time GNSS data with deep learning for improved PGD magnitude estimation* (23July2026, DOI10.1785/0120250220) describes training a detector using over700,000 synthetic displacement waveforms combined with real-time GNSS noise, preserving real earthquake data for inference. Ridgecrest replay illustrates filtering low-quality inputs before GFAST magnitude estimation, outperforming a simple SNR filter. This is relevant prior art for learned observation-quality gates rather than merely changing a magnitude distribution. The record alone does not verify exact1/3/5 clocks, sequence-independent validation, decoder/preprocessing causality, model architecture/code, or a compatible available GNSS cohort here. [USGS primary record](https://www.usgs.gov/publications/detecting-earthquakes-noisy-real-time-gnss-data-deep-learning-improved-pgd-magnitude).
