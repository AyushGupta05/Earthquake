# ROOT binding contract

This package is stdlib-only control logic, not an autonomous cloud launcher. ROOT must provide source-reviewed adapters. It performs no filesystem, subprocess, network or resource operation on import. The command builder returns a fixed systemd argv; the injected runner owns invocation, bounded stream observation and manager timeout containment. Neither test fixtures nor JSON `verified` flags constitute deployment proof.

## Gate and lifecycle

`controller.run_stage(gate, index, store, parent_adapter, clock=monotonic)` runs exactly one of fourteen stages. The same immutable gate, same boot/monotonic domain and same durable store must be used throughout. ROOT advances only from this call's returned `status == complete`, after independently verifying the closed artifacts. An exception before claim means no dispatch; an exception/uncertainty after exclusive claim is terminal and must be reconciled without rerunning. A failed or uncertain stage is never manually skipped. Calls at a later index require every preceding successful closure and original result pin. There is no retry/resume API.

Gate keys (exact): schema=`marked-sixfit-parent-gate-v1`, study=V2 fitting identity, feature_schema and feature_study=unchanged V1 identities, experiment_id safe lowercase alphanumeric/hyphen <=48, experiment_begin finite monotonic timestamp captured before Stage0, source_pins, runtime_pin, input_pins, funding_pin, storage_limit_bytes. All pins are `{bytes: positive integer, sha256: lowercase64}`. source_pins exact keys processor/operator/native/reference/parent/protocol bind COMPLETE reviewed manifests, not merely an entrypoint. input_pins exact keys feature_archive/feature_manifest/feature_authority/strong_results/strong_authority. Each input is <=16MiB. No TEST or arbitrary path key exists. ROOT supplies storage_limit_bytes explicitly; no default financial or disk permission is invented.

The strong authority must independently close all eight original B/F/H/T results (66 records each), checkpoints, original population and numerical/forward truth. It must be bound before Stage0, not obtained by new optimization. Missing authority forbids this complete comparison. Newly saved S/P/D still require ROOT's independent neural/scaler/checkpoint/numerical audit before a scientific conclusion. The controller's completion means bounded source execution and custody closure, not that independent audit or the scientific guards passed.

## Store

`store.write(logical_name, raw_bytes, replace=False, total_cap=gate.storage_limit_bytes)` must perform an atomic exclusive write unless replace is true, enforce the total cap atomically across writers, fsync file and containing directory, then return exactly `{status:'durable', pin:pin(raw_bytes)}`. Paths are resolved only beneath ROOT's fresh owned private output directory with no symlinks. `store.read(name)` returns exact bytes; `store.exists(name)` reports that logical artifact. All writes are read back and compared. Replacement is used only for a fit's latest_update.json; it must be atomic so interrupted replacement leaves the prior complete snapshot. Immutable claim.json implements the cross-process once-only fence. A duplicate claim must fail before any unit dispatch. Snapshots are capped at2MiB before writing. Returned in-memory failure when storage itself fails is evidence of incomplete custody, not a durable success.

## Parent adapter

`authorize(gate, stage_spec, now)` independently re-verifies current credit/resource authorization, published complete source manifests, target runtime/Linux tests, native agreement and strong comparator closure, exclusive unit availability, and the absence of any uncertain prior stage (including the previous in-memory return). Return exact `{authorized:True,gate_sha256,index,unit,funding_pin,expires,verified:{source_runtime:True,native_agreement:True,strong_closure:True,owned_unit_available:True}}`. expires is a finite same-domain monotonic lease covering the full manager interval at the actual dispatch. The controller does not invent/refresh funding facts. ROOT's authorized funding document is externally pinned; its amount/currency/credits truth lives in ROOT's authority, not fixture booleans.

`run(request, timeout)` invokes one fresh owned contained stage, with no shell interpretation or retries, returning `{code: int|None, timeout:bool, stdout:bytes, stderr:bytes, streams_complete:bool}` (optional exception type). Capture at most64KiB stdout/128KiB stderr, retaining separate stream hashes/count/truncation evidence in the adapter when exceeded; any unobserved/truncated stream sets streams_complete=False. Enforce timeout even if a child hangs; no unbounded wait. `stop(unit,timeout)` only stops this exact unit and returns a small JSON observation. `inspect(unit,timeout)` returns exact `{unit,result,active_state,control_group}`, from current authoritative OS state, never an assumed success. inactive/failed plus empty ControlGroup is necessary. Unknown cleanup remains incomplete. All adapter stop/inspection calls honor the supplied timeout, including zero (no blocking work).

`controller.systemd_command(request, absolute_python, child_code)` builds fixed MemoryMax2GiB/MemorySwapMax0/TasksMax64/CPUWeight10/TimeoutStopSec5/KillMode control-group/CUDA hidden/thread1 arguments and RuntimeMax360 or960. ROOT positively binds executable and child bootstrap bytes. Do not call with an ambient Python, unreviewed bootstrap or changed environment. ROOT's outer controller clock starts before the first child and must retain its original origin across separate invocations.

## Fresh child

Capture `source_begin = monotonic()` as the first bootstrap action, before scientific imports, binding, reading or loading. Then `child.execute(request,store,child_adapter,source_begin=source_begin)` calls only the appropriate frozen processor entrypoint. The processor retains its own original caps. Child report is durably written before final deadline checks; child_late_or_failed.json invalidates a previously written provisional report.

Child adapter `live(unit)` independently verifies current owned cgroup properties and numerical environment, returning exact `{unit,active:True,limits:stage_spec.limits,runtime_max_seconds:stage_spec.manager_seconds}`. It must verify one CPU numerical thread, hidden/uninitialized CUDA, memory/swap/tasks/CPUWeight/KillMode/stop/runtime limits; do not derive this return from requested values alone. `load(name,pin)` returns only a ROOT-bound named input's bytes. `bind(request, raw_inputs)` checks full source/runtime manifest bytes, original native authority and strong comparator truth BEFORE imports, imports only positively bound modules, decodes the immutable original V1 feature packet without changes, then returns exact processor/bindings/numeric/packet/strong_results/binding_receipt. binding_receipt=`{verified:True,gate_sha256,source_pins,runtime_pin,input_pins}` must reflect actual verification.

`processor` is the frozen sixfit module; `numeric` its frozen numeric_state module; `bindings` its frozen Bindings with matched Gaussian/reference/native modules; strong_results the eight positively decoded original records; packet unchanged V1. Frozen source first-clean manifest: SHA25604e102c441c33afed2a5ed821191a2e6dee0a22df76135195402f9f7fb3c60c7. Exact deployment pins are ROOT inputs. The separate source dependency contract copies included here are documentation only, not replacement implementations.

Source returns full numeric results into immutable stage_XX/result.json, plus initial/latest/final/history/forecast/failure evidence. Stage child_report.json binds result and all callback hashes; manager_return.json preserves bounded transport; post.json preserves cleanup; closed.json is the parent closure. Any late_or_failed.json or child_late_or_failed.json forbids advancement. A failure to persist final flags requires ROOT to treat the last in-memory return and unit custody as uncertain even if a provisional closed.json exists. Never reconstruct permission to continue from that file alone.
