# Sequential distribution research V4 — continuous evidence with identifiable controls

Public research only, 13 October 2026. This note changes no architecture, processing source, acquisition, resource controls, features or fits. It inspects primary public papers and public historical design documents; it does not inspect current candidate private data, forecasts or outcomes. Parent reports that the frozen V2 comparison stopped incomplete during H scoring at its fixed deadline, before T/C and the second seed. That is a computationally incomplete study, not evidence that age helps or fails. Frozen V2 remains unchanged. This note proposes a NEW, separately admitted experiment; it supplies no actual execution authority and no tested winner.

Recommendation: first test a **normalized continuous-mark extension of the observed activity process**, with explicit ordinary-feature and calendar-time controls. A second, more restrictive hypothesis tests shared normalization/gain uncertainty through a correlated continuous likelihood. Retaining more evidence is a plausible path to better high-magnitude accuracy; it cannot promise that a local 1-second prefix identifies an arbitrary earthquake's final magnitude.

This is a bounded primary-source search, not a global priority certification. ## Why binary-only updating may leave information unused

Let R_j be the existing exact native quarter-cell ratio of centered component power to pre-T0 noise power, with component maximum and fixed threshold9. Binary b_j=1[R_j>9] forgets differences among ratios within the same state. Two prefixes with the same binary path can have very different amplitudes, growth and component structure. Conditional on initial data, thresholding cannot add information about Mw; it can provide useful regularization in a small sample. Whether lost continuous marks carry *conditional* Mw information must be measured against controls, not assumed.

A prior learned from the first .25 seconds plus binary transitions also cannot use later spectral/phase morphology except through that binary path. Therefore an age-based arm beating an initial-only prior would not prove superiority over full-prefix waveform prediction. Continuous quarter power is still a compression of waveforms; retaining it does not make an information-preserving waveform method. The full-prefix control remains essential.

Threshold invariance is a representation check, not a physical magnitude law. Multiplying all signal and precontext counts by the same positive gain scales both centered powers and their noise powers by gain², so R and threshold9 are invariant away from the one-count power floor/quantization. The fixed floor breaks that idealization; signal-only scaling changes SNR. Unknown frequency response, component orientation, site amplification and source-path effects do not generally cancel. Even stable receiver active duration is not complete-response-calibrated displacement, moment release or source rupture duration. Existing LPVT/LPDT and source-duration papers cannot supply that missing calibration.

Every R_j uses the SAME estimated twelve-quarter pre-T0 noise reference. Nonoverlapping signal cells are therefore not independent normalized observations. A model conditional on the observed estimate and full past is a working conditional model; a short autoregressive history may still miss dependence from the shared reference. If normalization uncertainty is modeled explicitly as nu, carry q(m,nu|initial) jointly and update it with each new kernel before marginalizing, retaining the SAME nu across cells/deadlines. The observed state remains defined by the fixed measured R>9; latent nu must not reclassify cells or move the observed support boundary. g_b and state probabilities can depend on nu, but must still normalize on the original observed intervals for each nu. Independently redrawing nu per cell or multiplying separately noise-marginalized cumulative prefixes is not shared uncertainty propagation. Rank1 initially conditions on the fixed reference and tests continuous-mark value; rank2 separately tests coherent nuisance dependence. Do not mix both changes before the attribution controls.

There is a sharp 1-second limitation: if only the first complete .25-second cell is available at1, a candidate that conditions its initial prior on that cell receives no new suffix evidence at1. Any 1-second gain on such events must arise from better initial estimation or joint-training regularization, not a claimed new real-time measurement. Report this stratum prospectively.

## Ranked hypothesis 1: a threshold-consistent marked transition likelihood

**Narrow hypothesis:** continuous amplitude marks within observed active/quiet cells improve conditional Mw inference beyond binary run age, and any additional age effect survives an otherwise identical calendar-time model.

Use x_j=log(1+R_j), a=log(10), hence quiet x in[0,a] and active x>a. Let p_j(m,H_{j-1}) be the probability of a state change, with the existing observed preceding state, elapsed local time, run age and immutable initial context; H contains only observed past. For a candidate destination state b, define a normalized mark density g_b(x | m,H), supported ONLY in that state's interval. Then

    K_j(x | m,H) = P(b_j=b(x) | m,H) * g_b(x | m,H).

For observed binary states, this is a single probability-density factor, not two independent observations. Integrating K over the two disjoint intervals gives1. The quiet interval includes equality at9. A known exact-zero ratio needs a declared quiet atom with mass w0; the positive quiet density then has total mass1-w0. Do not add a post-data epsilon, silently discard zero events or treat quantization as physically continuous without stating the working approximation. One prototype g uses normal x densities truncated to the proper interval, with low-dimensional mean depending on m, elapsed time and previous mark; the atom and scale are fixed or TRAIN-estimated under a prospective protocol. Stable truncated-CDF differences must be tested in extreme tails.

A common error would use an unrestricted continuous amplitude density AND multiply an independent hazard for its deterministic threshold state. That product generally does not integrate to1 and can create spurious extra evidence. Another error would derive b from R and then claim both are independent sensors. The partitioned g construction avoids those errors. If the state probability is instead induced by a single unrestricted mark distribution, duration effects can enter that distribution directly; use that simpler arm as a comparator because a separate hazard may add no identifiable value.

The initial state/mark/first waveform is conditioned on ONCE in q0. New edges j>=2 contribute K_j once. The reported posterior is

    q_h(m) ∝ q0(m | initial) * product_(j=2..J(h)) K_j(x_j | m,H_(j-1)).

Sequential and joint evaluation must agree: the3-second state is the1-second state plus new edges, preserving preceding run ages. Do not multiply three cumulative posteriors. At deadlines the process is observed-prefix-censored: no final exit is added and future cells are integrated out. Quiet can reactivate. No receiver quietness is equated with permanent source arrest.

To isolate run age, compare the same mark model with C extra eta*log(1+r) against T extra eta*log(1+4u), preserving all other parameters and initial context. Their added terms coincide before the first reset and separate afterwards. An age-free control must retain the same global-time flexibility and real used capacity. Mark means should initially use the same history/time regressors across all arms; do not sneak extra reset features into one comparator.

**Falsifiers:** reject a special marked-duration claim if ordinary continuous features erase the gain; if a normalized mark-only autoregressive model performs equally; if C does not beat T after controlling calendar curvature; if shuffled within-state marks preserve the effect; if gain depends on unsupported near-zero normalization or station identity; or if proper/bulk/worst guards fail at any deadline/seed. Training NLL improvement alone does not count. This is a specialized observed-state emission model, closely related to established duration models; its empirical value and narrow EEW implementation, not generic HSMM machinery, are the potential contribution.

## Ranked hypothesis 2: collapse one shared observation nuisance instead of redrawing it

**Narrow hypothesis:** treating the same short precontext normalization/site-gain uncertainty as shared across quarter cells prevents repeated pseudo-certainty and stabilizes high-Mw predictions without hurting bulk accuracy.

A deliberately small working model for a suitable real-valued continuous feature y_j is

    y_j = a_j(H_(j-1),s) + b_j(H_(j-1),s)*m + g + e_j,
    g ~ Normal(0,tau²), e_(1:J) ~ Normal(0,Sigma_J).

Here s contains only operationally available immutable descriptors; Sigma may have a predeclared short-range correlation structure. Marginal covariance is V_J=Sigma_J+tau²*11'. Sequential updates use the Gaussian conditional distribution of new features given old features under this SAME V, not newly independent g draws. Schur-complement conditionals and the joint multivariate likelihood must agree. Shared random effects/correlated regression are standard; the project-specific test concerns this exact native short-noise reference and cross-deadline dependence.

If q0 is a Gaussian mixture prior BEFORE these amplitude observations, affine uncensored Gaussian features give an analytic Gaussian-mixture posterior. For prior component(k) mean mu_k and variance v_k, posterior precision is v_k^-1+b'V^-1b, posterior mean equals that variance times(mu_k/v_k+b'V^-1(y-a)); component evidence is a multivariate normal with covariance V+v_k*bb'. Its continuous NLL/CDF/CRPS admit ordinary mixture scoring and can supply a low-cost numerical comparator. Do not claim this analytic route covers nonlinear saturation, truncation, zero/censored marks, amplitude-dependent covariance or learned latent waveforms automatically.

The initial-data boundary is crucial: if the current q0 already conditions on initial amplitude, g and m are generally correlated. Appending an independent g prior is not correct marginalization. Either model their joint initial posterior explicitly, or use a common prior excluding the amplitude cells and include all those cells once in the joint observation likelihood. This changes the comparison protocol and needs new controls. A real-valued learned embedding is not automatically a normalized waveform likelihood; joint feature learning can collapse the feature/noise scale. Freeze a common encoder independently or account for its observation transformation and test collapse. Native nonnegative/quantized power also requires its observation support/zero handling; use analytic uncensored normal scoring only where the declared model genuinely permits it, never by dropping difficult common events.

**Identifiability veto:** if E[y|m,g]=beta*m+g and g is an unrestricted per-event offset, replacing m by m+d and g by g-beta*d leaves the observations unchanged. Mw cannot be recovered from that data model. Centering E[g|s]=0 with a proper variance, repeated-station evidence and separate TRAIN estimation supply statistical assumptions, not a proven physical amplitude anchor. Differences y_j-y_(j-1) remove g but also remove constant magnitude effects; they may destroy the main size signal. Gain/noise/sensor response/path effects are not interchangeable, and ambient SNR cannot certify displacement, seismic moment or a magnitude lower bound. Reject a shared-noise claim if an ordinary correlated/heteroscedastic likelihood or fixed robust residual achieves the same result, or if gain-prior choices dominate upper-tail predictions.

This second hypothesis is less immediately ready because normalization uncertainty, latent-site variance and serial model residuals are hard to separate in a small cohort. Do not join both new operators in the first experiment: that would prevent attribution and multiply numerical cost.
