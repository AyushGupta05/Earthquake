# Primary documentation pointers

No new primary page/API was fetched for this short design. These are documentation pointers already in the public research context, whose current contents were not reverified here. The frozen public V1 protocol supplies the actual parser/epoch semantics being proposed for reuse; strict-interior containment is a conservative study choice, not a claimed standard requirement.

- [GeoNet FDSN access](https://www.geonet.org.nz/data/access/FDSN): original request level/filter/time-scope reference cited by the public next-data-plan report; not proof of cached custody or waveform continuity.
- [GeoNet channel conventions](https://www.geonet.org.nz/data/supplementary/channels): literal E/N,1/2 and other naming families; not measured axes or a selected station's family.
- [FDSN StationXML reference](https://docs.fdsn.org/projects/stationxml/en/latest/reference.html) and [response representation](https://docs.fdsn.org/projects/stationxml/en/latest/response.html): epoch/rate/orientation/response element references; fragment/stage presence is not full response or calibration.
- [GeoNet AWS access](https://www.geonet.org.nz/data/access/aws): archive-access reference cited by the public next-data-plan report; metadata does not guarantee holdings or operational latency. This design performs no archive/AWS action.

No completed65-event support, scientific success, novelty or benchmark claim is attributed to these references. Root should verify any standard-specific detail needed for its normative successor protocol.
