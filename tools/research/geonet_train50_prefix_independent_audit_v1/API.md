# Independent NEW50 native replay API V1

Protocol `geonet-TRAIN50-prefix-independent-audit-v1`. Python3.9-compatible source; no NEW50 producer implementation or tests were read/imported. The byte-identical public producer schema, inherited contract and two addenda are the comparison contract. The authored old independentV2 primitives/scanner are copied with provenance in SOURCE_ORIGINS.json.

`auditor.audit(plan_bytes, producer_bytes, bounded_reader, expected)` authenticates exact builtin bytes and positive pins, validates the fixed projection and complete producer identity/claims before body reads, then independently fresh-decodes each selected original raw record. `expected` is exactly `{plan:{bytes,sha256},producer:{bytes,sha256}}`. Input caps: plan131072B, producer67108864B. `bounded_reader(name,cap)` must return exact builtin bytes from a parent-controlled, immutable read-only namespace; only `000.body.private` through `012.body.private` for positive batches are requested, with cap equal to the original bound bytes plus one. Original negative/no-selection batches are not read. Exact body byte length/SHA is rechecked. No discovery, retry, provider access or filesystem enumeration exists here.

Return exactly `{protocol,agreement,fresh_complete,audit_pass,reason,rows,cells,fresh_result}`. Fixed rows50/cells150. `audit_pass` is true only when the fresh replay is complete and its canonical JSON is byte-identical to the pinned producer JSON. Reason supported, replay_disagreement or fresh_incomplete. This private result is bounded to64MiB; if the wrapper cannot hold both evidence and verdict within the same cap it raises a declared rejection and emits no pass. Preflight/custody/schema failures raise strict.Reject; parent must retain that as failed audit. An incomplete producer is rejected before decoding, never promoted by a second attempt.

`replay.replay(plan, body_reader, decoder=native_decode.decode_record, wall_seconds=300)` is the underlying fixed-cardinality replay. `body_reader(ordinal,expected_bytes)` returns bounded positive bytes. The injected decoder is an invented-test seam only; actual replay uses fresh pinned ObsPy1.5.1 per raw record. Successful callback exactly `{start_ns,rate,dtype,values}`, builtin signed64 start, builtin float rate, dtype i4/f4/f8 and one-dimensional native array. Returned scalar length is charged before reconciliation. The independent ObservedDecodeFailure(ValueError) class carries exact builtin nonnegative signed64 observed_samples; all obtained trace-array scalar sizes are counted before identity/dtype/count/cardinality rejection. Invalid counts are whole runtime_failure; per-body/whole overdelivery is whole sample_cap. No-array declared vendor failures are ordinary unknown without invented counts. Unexpected RuntimeError/MemoryError fail the whole replay.

The result retains all50 local ordinals0..49/global65..114 TRAIN rows and150 original1/3/5 deadline cells, plus13 batches with the final original[48,49] pair. Nullable selections/metadata and all failed outcomes remain unknown. Long station literals are not truncated to native-header width. Raw custody, interpreted exact rational timing, per-record native sample hashes and ordered crop/view hashes are compared; none establishes raw-clock truth, calibration, physical axes, clipping, online timing, model support, accuracy or novelty.
