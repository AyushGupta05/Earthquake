# Source-only C/H numerical core

This core implements the existing public receiver-activity renewal protocol, without Cx or a new experiment. The normative inherited protocol is `work/earthquake_tail_innovation_candidates_v2/PROTOCOL.md`, SHA256 989c6e5f13e3589adad58b13d378630f03d0d66932ba8e5c04b916e225d3d61a. No actual-data invocation, fitting, GPU, data request or cloud mutation is authorized by this module.

The caller supplies only positively qualified, completely received quarter-second states, first-cell-only initial embedding z and frozen context c. States have length 1..20; b1 is initial evidence. Clock/noise/channel qualification and independent whole-input custody are upstream responsibilities, not asserted by this API. Passing later features as z/c would be leakage. The optional `prefix_cells` likelihood argument restricts evidence to the requested observed prefix; it does not infer clocks or create data availability.

Five-Gaussian head layout is five logits, five uncapped means, five rho values. Weights use softmax, sigmas use .05+softplus(rho), permitting the representable limiting floor .05. Literal finite mixtures may include zero weights. Parameters own read-only float64 array copies. No output-support clipping or hypothesis-driven tail correction is applied.

Hazard order is on, off. C uses two extra coefficients for current log-run-age. H sets that duration term absent and instead uses those two coefficients for fixed initial products z0*z1 (on) and z0*c0 (off), requiring at least two z and one c dimensions. These effective interactions preserve the parameter count; they are not magnitude interactions. All other coefficients and the base density are identical API families. H can vary with elapsed local time and is age-free, not generally stationary geometric.

The log likelihood includes exactly observed edges j=2..J, with local time .25*(j-1), preceding state and preceding run age. Stays are censored exposure, with no appended terminal exit. Quiet-to-active edges are legal. Extending a prefix preserves preceding ages; resetting run age at the 1/3/5 boundaries is invalid. The joint loss is base Mw NLL plus observed sequence Bernoulli NLL. It does not subtract the posterior log normalizer or implement a posterior-normalized conditional training loss.

Inference uses fixed 64- and 128-node Gauss-Hermite quadrature per Gaussian, and independent all-real-line adaptive SciPy integration for every component. Adaptive integration uses the strictly log-concave Gaussian times affine-logistic likelihood: its derivative has a unique mode within a deterministic analytic bracket, and a local curvature scale avoids an underflowing mass. Neither the mode bracket nor curvature scaling truncates the integral. Adaptive failures, overflows, unresolved modes and GH disagreements remain numerical failures; models are never repaired by clipping sigma, magnitude, hazard or posterior support.

`checked_inference` accepts only when every pair of GH64/GH128/adaptive log-normalizer, mean and label NLL differs by at most 1e-4. Failed numerical acceptance retains all three integrals and errors. Exceptions carry no accepted forecast. These functions provide the primary density-mean action and NLL, not a calibrated coverage, median or CRPS claim. Quantile/CRPS and a differentiable Torch trainer are deliberately outside this low-level preparation; adding them requires separately reviewed source and appropriate numerical checks.

Invented tests cover state/reactivation/run-age bookkeeping, prefix invariance, disjoint evidence, absence of terminal exits, exact H age independence and effective replacement parameters, shared base density, magnitude-independent likelihood returning the base posterior, joint versus posterior loss, moderate integration, far labels, sigma floor/broad regimes, uncapped magnitude means and retained fixed-GH failures. No test verifies magnitude predictability, novelty, scientific gain, waveform availability or bulk preservation. Root's waveform-information, activity-variation/support and controlled-experiment gates remain required before any fit.
