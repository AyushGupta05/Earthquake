# TRAIN-only native adapter V1

`adapter.run(plan, qualified_v2, bodies, decode_record, metadata, external)` returns private `{schema, results, summary, decoded_train_records, adapter_denials, claims}`. No IO, cloud control, requests, fits, catalogue lookup or physical calibration. Python 3.9+. Import the frozen qualifier V2 `producer`/`scanner` and frozen receiver-activity `activity` modules through root-controlled source paths. Do not import an unverified replacement.

`plan`, `bodies`, and injected per-record decoder follow frozen qualifier V2 SCHEMA. `qualified_v2` is the complete result positively agreed with fresh independent V2 audit; that authority, immutable/read-only original inputs, exact source/runtime pins, original metadata and live resource controls belong to root. The adapter checks the structure/bindings it consumes but cannot authenticate the external audit with a boolean.

`metadata` is exactly 65 original compact-slot-ordered builtin dicts `{slot, mw, group, group_eligible}`: integer slot 0..64; builtin finite numeric Mw -5..15; opaque group string length 1..128 or null; boolean operational group eligibility. Root supplies typed original Mw and pre-waveform frozen grouping. No grouping from waveforms or labels. `external` is exactly frozen activity's `{grouping_frozen:bool, prior_support_floor_pass:bool}`; these remain assertions. Prior support floors remain root-owned and do not require DEV activity reads.

Plan/result original clocks, partitions, families, row/batch ordinals, 1/3/5 cutoffs and joint support must agree. All 65 rows and 195 outcomes are retained. Only TRAIN rows with all three joint-complete cells, known family, eligible known group, original P>=T0 and P+0.25s<=T0+1s receive arrays. DEV and all denied TRAIN rows pass `components=None`; they cause no decoder invocation. Original pre-T0 picks are never clamped or replaced: because frozen extraction rejects them before its denied-row handling, the adapter emits a compatible deferred DEV / unsupported TRAIN three-horizon placeholder directly, retaining the original plan/result clocks. Whole body byte hashing and structural header reading are allowed but DEV-only numeric records are not decoded.

For each eligible TRAIN event, reconstruct the union of record references in its required literal component 1/3/5 views. Verify original full body pin; record offset/length/header identity/rational interpreted start/rate/period/routing; raw record SHA; callback exact integer start and nominal rational rate tolerance, dtype, observed length; dtype-prefixed little-endian full native sample SHA; and every horizon's exact half-open crop piece fields/sample hash/ordered view hash. Reject disagreements without substituting rows, clocks, channels or samples. The adapter reuses frozen qualifier hash/crop arithmetic, so this is custody checking, not a new independent decoder.

Keep full native records as separate pieces `{start_ns, rational_period, values}` with builtin sample scalars, ordered by original native integer start then record ordinal. No merge, trim, resample, interpolation, repair, phase alignment or rotation. Full-record sample hashes are checked before scalar conversion. Maximum 32768 pieces/8 million samples across required components per event, inherited body and whole caps; one event's arrays at a time. A numeric failure in a later activity window stays that source's unknown result. Raw full-record hashing may touch overdelivery for integrity but never adds a future activity cell.

Structural/hash mismatch raises bounded `InvalidInput`; no partial cohort promotion. `activity.extract_event` and `activity.summarize` own noise, renewal-state, current-prefix, denominator and transition gate arithmetic. Return no arrays; bounded private canonical JSON <=16MiB. Root must enforce read-only hashes, 1GiB/swap0/32 tasks, 300s source wall within 360s manager deadline, output/stderr bounds and preserve failures. Adapter wall limit 300s. Always-false claims include fit authority, physical interpretation, accuracy, novelty and published superiority. A passing gate permits a separately reviewed model experiment only.

An exact native period exceeding the frozen activity numerator/denominator bounds is retained as unsupported before any event decoder invocation, not approximated. Private `adapter_denials` records ordered compact slot and bounded `pre_t0_pick` or `activity_period_bound` reason. Qualification itself remains unchanged.
