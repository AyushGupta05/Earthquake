It accepts only a completed, preserved all-four grid with normal supervisor/worker exits, exact original provenance and split identities, and the fixed prospective1e-9 absolute plus1e-9 relative comparison tolerance.

Actual runtime/index generation must be bound; different local NumPy requires the original private index arrays. A separate CPU-only restricted state check uses the existing worker Python/Torch versions and verified checkpoint bytes without constructing a model or forwarding waveforms.

The audit verifies saved parameters and recorded training pairing. It cannot establish fresh waveform forward equality, sequence independence, high-magnitude generalization or novelty.
